# 类别2｜动物（animals）

**所属单元：** 第四章 · 动植物主题  
**themeId：** `animals`

**说明：** 介绍=简介+相关诗句（用户原文）。

## 背景介绍

```text
在古典诗词中，诗人常常借飞鸟走兽表达内心情绪，各类动物形成相对固定的意象内涵。掌握动物意象的寓意，有助于准确把握诗歌情感，提升古诗词赏析能力。
```

## 贴纸介绍

- **猿猴**：猿啼凄厉哀婉，猿象征悲凉萧瑟，烘托游子漂泊他乡的愁苦心境。相关诗句：两岸猿声啼不住，轻舟已过万重山。（李白《早发白帝城》）
- **大雁**：秋季大雁向南归巢，大雁象征游子思乡；古人认为鸿雁能够传递书信，寄托绵长思念。相关诗句：乡书何处达？归雁洛阳边。（王湾《次北固山下》）
- **杜鹃**：杜鹃啼声凄苦，杜鹃象征哀伤悲凉，常用来寄托离愁、思念与心中忧思。相关诗句：杨花落尽子规啼，闻道龙标过五溪。（李白《闻王昌龄左迁龙标遥有此寄》）
- **燕子**：燕子年年归返旧巢，燕子象征世事变迁，抒发物是人非的感慨；双燕也象征美好爱情。相关诗句：旧时王谢堂前燕，飞入寻常百姓家。（刘禹锡《乌衣巷》）
