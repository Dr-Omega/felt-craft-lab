# M6 finite relation evidence strategy

This batch introduces reproducible algorithm rules, not an assertion that the
rules were previously approved or that a source drawing has one true assembly.
`A_TO_B` means source A is visually below B, or piece A precedes B, according to
the record's distinct kind. Region and final Piece endpoints are never mixed.

`visual_relations(observed, labels, layered=None)` measures actual Region-domain
shared-boundary length and positive-area overlap. Contact, color, enclosure and
source order alone leave visual order UNRESOLVED. Every inspected pair receives
located evidence; any unrecorded pair remains NOT_EVALUATED.

Directional proof has a deliberately finite scope: M5 SUPPORTED evidence with an
explicit `selectedLayerIds` list, uniform-color source objects, a unique opaque
layer-to-Region and Region-to-layer mapping, and actual overlapping source alpha.
Ownership is recomputed from the selected canvas RGBA arrays. Translucent paint
invalidates unique opaque ownership; unselected objects cannot alter it. A witness
must be a presently visible opaque pixel of the queried upper Region covering the
original lower alpha mask. A third layer hiding the whole overlap prevents this
proof. Evidence records source SHA, both mask hashes, visible witness hash/count,
sample coordinate and source IDs. Complex textured or multi-Region source layers
remain unresolved rather than attributing their entire mask to an arbitrary Region.
Raster identity is explicit `regionLabel`, or the current adapter's `R<integer>`
identifier. Other names are not guessed into a raster label.

`assembly_relations(observed, plan, visual, manual_records=None)` first independently
validates the actual M7 plan with `validate_plan`, including Base support, exact
exposures, source coverage and split geometry. Invalid support/exposure is a hard
error, never an excuse to downgrade uncertainty. For valid conservative plans,
disjoint supported ordinary VISIBLE pieces do not need the original hidden order;
their unresolved visual records can be NON_BLOCKING with measured area evidence.
Base exposure is measured rather than treating an empty VISIBLE list as proof.

Each actual final Piece pair is examined after splitting. Positive Base/VISIBLE
intersection yields support-before-cover precedence. No positive-area intersection
yields explicitly evidenced NO_RELATION. Same-role positive overlap is rejected.
No total order is invented for independent pieces. Region-to-final-Piece mappings
and actual geometry hashes are saved, and all endpoints use current split IDs.

The relation validator rejects missing or mistyped endpoints, self-loops, cycles,
opposite directions, invalid statuses/impact, absent evidence, and a directional
assertion conflicting with NO_RELATION in either input order. Caller-supplied
manual records and evidence remain unchanged and are checked against derived
records; a blocking manual unresolved record remains blocking. No manual record,
signature or confirmation is generated by the algorithm.

Tests use the real M5 SVG/PSD parsers and genuine M7 plans, including actual ring
splitting. They exercise selected-only evidence, alpha blending, third-layer
occlusion, flat unknown relations, final independent pairs, split mapping, missing
support/exposure, direction/NO_RELATION conflict, cycles and supplied pending records.
This produces algorithm evidence, not visual/manufacturing acceptance.

Assembly evaluation precomputes Region-to-VISIBLE indices, unsupported area per
piece, exposure totals, exact geometry bytes, bounds and hashes. Bounding boxes
that cannot intersect with positive area skip the expensive intersection only;
the full pair record is still emitted. An optional keyword-only `geometry_cache`
can be one call-local dictionary shared across candidate evaluations. It is
forwarded to `validate_plan`; geometry measurements are keyed by operation and
both exact WKB operands. Plan IDs, metadata and validation verdicts are never
cache keys/results. All contracts, endpoint checks and manual constraints run
again. Tests compare every cached/fresh record and prove that moving geometry or
changing source references under the same plan ID is still rejected.
