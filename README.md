# felt-craft-lab

不织布儿童美育创作工具（Electron + Vue3 + TypeScript 基线，含组长 AI 服务线）。

## 技术栈

- Electron + electron-vite + Vue 3 + TypeScript
- Vitest + electron-builder
- AI Gateway：Flask（`backend/`，开发本机 / 正式远端；不打进 Electron 安装包）

## 包管理器

唯一包管理器：**npm**（Node.js >= 22.12.0）。请只使用 `package-lock.json`。

## 目录映射

```text
src/main/          Electron 主进程、felt-resource、AI Gateway 代理
src/preload/       contextBridge（含 electronAPI.ai.*）
src/renderer/      Vue3 Renderer（经 Preload 调 AI，不直连 Flask）
src/shared/        共享契约与 ResourceRef 解析（Contracts 由 XR 维护）
backend/           AI 安全代理：ASR / QA / TTS（远端 Gateway / 本地开发）
src/renderer/src/services/  正式 AudioService / AnimationService / ai.client
frontend/                  Flask 浏览器 demo（非正式打包入口）
assets/generated/  正式打包资源（material / audio 固件）
assets/demo/       联调示例（不进入 electron-builder extraResources）
docs/              架构与 AI 对接文档
tests/             契约与资源解析测试
```

资源引用协议：`felt-resource:`（见 `docs/architecture/resource-resolver.md`）。  
固定介绍语音：`felt-resource://audio/<file>.mp3`  
动态 TTS（Main 落盘）：`felt-resource://audio/dynamic/<hash>.mp3`

SXY 对接说明：**`docs/ai-services/SXY对接指南.md`**  
分支 / PR 状态请看对应 Pull Request 或 `docs/ai-services/`，勿在本 README 写死当前分支。

## 常用命令（完整工程）

Windows 本地完整启动（含网关、桌面及算法路径检查）：先按 [本地配置说明](docs/LOCAL_TEST_SETUP.md) 完成首次安装，再双击根目录 `Start-Felt-Craft.cmd`。更新代码不要覆盖自己的 `backend/.env`、`.env.local` 和持久数据；密钥、Python 环境与模型不随 GitHub 分发。


```bat
cd backend
双击 启动第1步.bat
```

## 彩色裁片图纸

界面入口的临时调整见[界面变更记录](docs/UI_CHANGELOG.md)。

个人作品中的创作图画展示画面，故事卡展示已确认故事卡的缩略布局，制作图纸展示已生成 PDF 的首张裁片页。完整作品按“画面、故事、操作区”三栏横向排列，每行一个作品；“打开”回到创作画布，“图纸”直接进入图纸页。移除独立上传快捷键，保留作品上的发布、撤回与确认删除流程。

导出时将 PDF、首张缩略图、尺寸和背景模式保存到本机 IndexedDB，之后可从制作图纸分类重开或再次下载。记录按账号及作品内容指纹匹配，不把旧图纸当作修改后的新版；删除作品同时删除关联图纸记录。本机图纸文件不纳入当前云端工作区同步；旧版本未记录的导出需重新导出一次。

已保存作品 → 图层展开 → 下一步 → 准备图纸排版 → 导出。用户提供的春节 PSD 直接从各个原始单色层的透明边界读取裁剪轮廓，无需拆分算法；普通图片仅使用与来源一致的现成轮廓，缺失时提示，不自动启动或重试拆分。

导出为彩色色块 A4 多页 PDF，不同颜色共用纸张，按元素及内部制作层序依次排版，同一层的离散裁片保留相对位置并作为一组排列；优先利用已有页面空位，放不下再续页。图层组之间保留 6 mm 操作间距并为编号预留位置，预览与 PDF 都保留对应层的实色、镂空及裁剪边界。默认成品长边 18 cm，可在导出时修改；有真实作品背景时以完整画布为尺寸基准，否则以全部前景素材的整体范围为基准。“一本书”对应在安全留边及编号空间内等比例适配 A4 的最大尺寸（按内容选择横向或纵向），整体最大不超过 A4，不跨页拆开单层。背景与前景裁片保持同一比例，不独立拉大。图纸仅保留色块与“元素层序-内部制作层序”两级编号，均自下往上；同一制作层只标一次编号。真实作品背景参与第一层计数，UI 白纸不计层序也不导出。

导出页采用透明底的横屏图层预览，按元素及制作层序从左往右排列，所有图层使用共同的显示比例；同层离散裁片保留相对位置，每层只标一次编号。屏幕预览不显示 A4 白纸矩形，实际 PDF 仍使用上述 A4 物理排版。

当前只保留排版，不改变输入轮廓：不自动合并底板、吸收小色块、删除细条或填孔。近期拆分运行策略与手工简化实验尚未获得认可，已独立保留，不属于本次正式集成内容。后续需单独评审后才能重新接入；不得随 PDF 排版一起提交。

爆炸图选择显示作品背景时，导出背景已有的 PSD 制作层；选择隐藏作品背景时，背景仍按同一比例作为完整彩图打印，不拆内部层。用户明确设置的画布底色也属于作品背景，界面默认白底不属于作品。缺失背景原始分层时不自动启动拆分算法，可选择完整背景打印。切换背景选项后会重新准备图纸，避免沿用上次排版。所有裁片先确定唯一比例再分页，统一预留约 12 mm 安全边距和 6 mm 编号空间；“一本书”表示等比适配 A4 可排版区域，并非无边距铺满整张纸，不单独缩小某一裁片。打印选“实际大小 / 100%”，关闭“适合页面”；公共打印网站仍可能忽略文件设置，需实测校准。裁片页不添加标题、色号、页码、说明或校准线。现有几何验证状态与实物制作验证状态分别保留。

最终 PDF 顺序为：实际尺寸彩色裁片 → 各元素按底到顶逐层叠放 → 各完整元素按保存位置与层序叠到背景上。步骤页仅在导出时生成，不出现在 UI 预览；采用紧凑的小图排版，每步显示新增部分缩略图、对应裁片序号和累计效果，保留必要的元素名。元素内每个制作层（含同层离散小配件）只对应一步；背景选择拆层时也有内部步骤，选择整张打印时只作为整体叠放的底图。

## 用户提供的春节 PSD 素材

正式版与桌面 Demo 共用新版分享区：双列手绘卡片、每次进入随机 1～2 行故事摘要、现有手绘默认头像、图文详情、点赞/取消、专家点评查看，以及自己的分享管理菜单。两版通过相同接口分别读取各自数据库；Demo 中恢复的八篇作品、预设点赞及点评仅为演示数据，不写入正式数据库，也不作为真实用户或专家参与的证明。只有 Demo 的图片生成入口固定返回福娃，普通启动保留真实生成流程；独立 HTML 和历史演示组件仅保留作参考，不挂载到运行页面。

新发布时上传已确认故事的标题和正文快照，旧帖子缺少正文时显示空状态，不擅自补写；需要补上故事可撤回后重新发布。教师点评仍按原角色和作品类型校验。取消点赞不追溯扣回既有奖励，反复取消/再点赞不会重复产生奖励。同一分享的“撤回发布”和“删除”均只移除公开分享，保留本机作品。升级后须重启后端加载新的分享接口；本地启动器会识别旧服务，不会自动停止用户进程。

春节「春联大门」引导教学按用户提供的 1686×960 参考图设置三个目标：灯笼左上、红包右侧、饺子左下，位置和尺寸等比缩放。放对并听完讲解后自动推进，三项完成后解锁主题并统一表扬；福娃不参与教学任务，自由创作画布不预放素材。

2026-10-17 的背景、灯笼、饺子、红包已作为新素材快照接入，历史快照与旧作品不覆盖。前景 PSD 可按原始层换色、保存重开并导出彩色裁片 PDF；爆炸图按完整元素与背景展示画布上下顺序，不拆开元素内部颜色层。不覆盖源图、不重新分割或简化图形。五份原始 PSD、全部 24 层（含红包隐藏背景）、层序、坐标及来源哈希保留。

双击 `Start-Felt-Craft-Demo.cmd` 启动演示版：图片生成任意描述固定使用福娃并保留 8 层；问一问、ASR 等非图片接口仍真实调用。普通启动和构建不启用该替换；Demo 开关只在本次进程中设置。范围、使用方式及复现见 [PSD 素材接入记录](docs/PROVIDED_PSD_DEMO_ASSETS.md)。

Demo 使用独立网关 `8789`、开发页面端口 `5175` 和 `tmp/demo-data/` 数据目录；正式版网关仍为 `8788`，既有账号与数据不迁移、不覆盖。已准备演示账号“可乐”：500 金币、66 钻石、首次自动引导和一封未领取的点赞邮件。账号密码不写入仓库。准备脚本 `scripts/prepare-demo-account.py` 只接受标准输入中的账号密码，显式执行时幂等补充 Demo 数据，不在启动时重置余额或引导状态；准备当天的每日钻石已登记，登录不会把 66 自动变为 67。后续正常签到和领取奖励仍会改变余额。
