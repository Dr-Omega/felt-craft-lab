# 彩色裁片与叠放指导 PDF 导出 PRD

版本：V1.0\
日期：2026-10-19\
范围：仅描述已保存作品的图纸导出功能，不包含创作、教学解锁、素材生成或分享功能。\
状态：依据已确认的产品要求补录；主要能力已在本地实现，发布状态与代码提交状态另行管理。

## 1. 功能目标

将数字作品转成一份便于打印、裁剪和照着拼装的不织布制作图纸。使用者应能看清：要剪哪些裁片、每个元素内部如何逐层制作，以及做好的元素怎样叠放成完整作品。

导出结果应保留作品的实际颜色和层序，不以界面截图、黑白轮廓集合或单纯爆炸图代替制作图纸。尽量节约纸张，文字仅用于必要的识别，不增加大段讲解。

目标使用者：进行手工制作的儿童，以及协助打印、裁剪和拼装的家长或教师。

## 2. 范围与前提

### 2.1 本期包含

- 输出一个包含彩色裁片和叠放步骤的多页 PDF。
- 读取作品已保存的颜色、元素位置、缩放、旋转、可见状态和上下顺序。
- 对已有可靠分层的素材生成逐层制作图；同一元素的多个实例分别编号。
- 支持背景拆层制作、背景整张打印，以及作品没有真实背景的情况。
- 支持具体尺寸和大小比喻；整体成品最大适配一张 A4。
- UI 显示横屏裁片预览；制作步骤只加入最终 PDF。

### 2.2 数据前提与不包含项

- 素材必须已有与保存版本匹配的图层、颜色、轮廓和制作顺序。当前已接入的 PSD 分层素材可直接复用；其他图片需已有可用的分层结果。
- 本功能是通用的数据驱动导出，不绑定某个主题、元素名称、固定图层数量或固定摆放位置；但不等于已具备任意 PSD 文件的通用上传、解析和入库能力。
- 不在导出时启动图片生成、图像拆分或补全算法，也不接入尚未认可的色块合并、细条清理、填孔等实验处理。
- 不根据颜色重新分层，不将同色的不同制作层合并，不强制每种颜色独占一页。
- 不自动纠正原始分层或制作顺序；源数据错误不能靠排版掩盖。
- 不包含缝份、胶位、材料厚度补偿、刀模加工、跨页拼接或实物可制造性认证。

## 3. 核心概念与编号

“元素”是画布上的完整素材实例；真实作品背景也作为一个整体元素。“制作层”是该元素内部从底到顶叠放的一层材料。同一制作层可以包含多个不连通的小配件。

统一采用两级编号 `元素序号-制作层序号`，例如 `3-2` 表示第 3 个元素的第 2 个制作层。

- 元素按保存作品中的底到顶顺序编号。存在真实背景时，背景为元素 `1`；没有真实背景时，第一个前景元素从 `1` 开始，不保留空背景编号。
- 每个元素内部按已有制作层序从底到顶编号，不因 PDF 排版位置改变编号。
- 同层离散配件共用一个编号，保留相对位置，不另增零件序号。
- 相同素材放入两次时，按两个独立元素处理，避免制作数量混淆。
- UI 默认纸面、装饰花边和页面底色不属于作品，不参与编号。

## 4. 用户流程

1. 从已保存作品进入图层展开页，确认元素上下顺序及背景选项。
2. 进入导出页，点击“准备图纸排版”，读取已有图层并显示裁片预览。
3. 点击“导出”，选择具体尺寸或大小比喻，确认生成 PDF。
4. 下载一个 PDF 文件，依次完成裁剪、元素制作、整体拼装。

背景选项变化后，旧的准备结果失效，必须按新选择重新准备图纸。重复导出可以选择其他尺寸，但不得修改保存的作品或源素材。

## 5. PDF 内容与固定顺序

PDF 必须依次包含以下三部分，不新增封面或介绍页。

### 5.1 第一部分：彩色裁片图纸

用途：按实际成品比例描摹或裁剪材料。

- 输出每个制作层的实色色块和裁剪边界，不仅输出黑白轮廓。白色材料仍为真实白色，并保留可辨认的边界。
- 保留既有轮廓、真实镂空和同层离散配件，不自行简化或吸收细节。
- 背景与前景、各元素与内部各层使用统一物理比例，不为填满空位单独放大或缩小某一块。
- 按元素和内部制作层序组织排版；不同颜色可共用纸张。允许后续的小图层利用前页剩余空间，因此纸面阅读位置不替代制作编号。
- 同层离散配件作为一组排布，不能为节约纸张任意打散其相对关系。
- 当前图层组间采用约 6 mm 操作间距，为编号留出位置；空间不足自动续页。
- 大图层统一适配 A4 留边区域，四周约 12 mm，另留编号空间；不再顶到纸边。不添加装饰边框、打印范围框或校准线。
- 裁片旁仅标两级编号；不增加标题、长说明、色号、字体名称、页码或免责声明。

### 5.2 第二部分：各元素逐层制作图

用途：说明一个完整元素是怎样由内部各制作层叠成的。

- 按元素编号顺序逐个展示，各元素内部按制作层从底到顶推进。
- 每增加一个制作层，输出一张累计效果图，保留之前已经叠好的所有层；不是仅重复展示单独裁片。
- 每步包含新增层缩略图、与裁片页一致的编号（如 `+ 3-2`）、简洁方向指示，以及叠放后的累计效果。
- 同一层的多个离散配件在同一步加入，不拆成多步。
- 元素的各步使用同一视角和固定范围，避免上一张突然变大、下一张突然变小造成位置误判。
- 图示可缩小以节约打印资源，但不能改变形状比例；它们不是实际尺寸裁剪模板。
- 仅保留必要的元素编号与名称。当前按每行三张紧凑排布，放不下自动续页，跨页重复必要的元素标识。
- 背景选择拆层时，也生成背景内部的制作步骤；背景整张打印时，不虚构内部制作步骤。

### 5.3 第三部分：整体拼装图

用途：说明做好的完整元素如何放到背景上，形成最终作品。

- 有真实背景时，先展示背景，再按保存的上下顺序，每次增加一个完整元素；无真实背景时从第一个元素开始。
- 每步包含新增完整元素缩略图、元素编号（如 `+ 3`），以及加入后的累计画面。
- 使用保存作品的实际位置、缩放、旋转、遮挡关系和颜色，不能重新自动布局。
- 所有步骤保持同一画面范围；最后一步应与保存作品的实际内容一致，排除 UI 纸面和装饰。
- 当前按每行两张排布，以便看清整体位置关系。此部分在各元素制作步骤之后另起页面。
- 仅使用“整体叠放”等必要标识，不增加大段拼装说明。

## 6. 背景处理规则

背景需区分“用户作品里的真实背景”和“界面呈现用的底色”。用户明确设置的画布底色属于作品背景；默认 UI 白底不属于作品。

| 作品与爆炸图选择 | 裁片部分 | 元素制作部分 | 整体拼装部分 |
| --- | --- | --- | --- |
| 有真实背景，选择显示背景 | 导出背景已有的各个制作层 | 展示背景逐层累计过程 | 使用完成后的背景作为底图 |
| 有真实背景，选择隐藏背景 | 背景按同一成品比例整张彩色打印，不拆内部层 | 不生成背景内部步骤 | 仍使用完整背景作为底图 |
| 作品本来没有真实背景 | 不导出背景或默认白纸 | 无背景制作步骤 | 从第一个前景元素开始 |

这里的“隐藏背景”只决定背景是否参与拆层制作，不表示从最终打印材料中删除真实背景。

需要拆层但背景缺少可用图层时，应明确提示；用户可切换到整张打印。不得擅自启动拆分算法，也不得默默漏掉背景。

## 7. 尺寸与纸张

### 7.1 成品尺寸

- 默认适配 18 × 18 cm 范围，保持比例，因此成品长边通常为 18 cm。
- 具体尺寸输入表示可容纳成品的宽高范围，不拉伸作品以强行匹配长宽比。
- “一个鸡蛋”：成品长边约 6 cm；“一个苹果”：成品长边约 8 cm。
- “一本书”：等比例放入一张 A4 安全打印区域的最大尺寸，而不是铺满纸边。
- A4 物理纸张为 210 × 297 mm。四周约 12 mm 留白，另预留 6 mm 编号空间：横向裁片区域最大 273 × 180 mm，纵向为 186 × 267 mm；正方形最大为 186 × 186 mm。
- 大于 A4 的尺寸请求按整体共同缩放比例限制到 A4 上限，不单独压缩某个元素，不将单个背景拆成跨页拼接图。
- “最大适配 A4”不等于拉伸或裁切来铺满纸面：长宽比不一致时允许留白，须保留完整作品内容。

有真实背景时，以完整作品画布为尺寸基准；没有真实背景时，以全部可见前景组成的整体范围为基准。两种背景导出模式下，同一作品的物理比例必须相同。

### 7.2 打印约束

- 裁片 PDF 使用 A4，按实际尺寸打印；步骤页独立使用紧凑示意比例。
- 文件不得额外绘制打印边框。为普通裁片排版保留空位，不等于给纸张添加边框。
- 整套裁片在分页前使用同一个比例适配上述区域，跨页仅平移；实色轮廓使用 0.3 mm 纯黑实线，保留真实孔洞，不改变路径。PDF 声明实际大小打印，但公共打印网站可能忽略；仍需选择实际大小/100%，不能保证第三方打印设置。
- 校准页作为独立 PDF 提供，不并入正式裁片及指导图，不给正式图纸添加说明文字。
- 该约束可记录于产品文档，不在用户已要求精简的页面或 PDF 中自动追加提示栏。

## 8. UI 与导出结果的边界

- 爆炸图展示完整元素与背景之间的上下顺序，不把元素内部颜色层当作独立场景元素展开。
- 导出页展示横屏、透明底的制作层预览；不叠加 A4 白纸矩形，不重复绘制页面背景。
- 屏幕上的排列服务于浏览，实际 PDF 的 A4 分页服务于打印，两者不必位置完全一致，但层、颜色、编号和相对比例必须一致。
- 各元素制作图及整体拼装步骤只生成到最终 PDF，不加入 UI 预览，不新增对应页面或导航步骤。
- 不恢复已移除的常驻说明栏、排版说明段落；仅在准备中、导出中或失败时显示必要状态。

## 9. 数据一致性与异常

- 以本次导出的已保存作品及固定素材版本为依据，不能使用其他作品的最近任务、未保存的换色或较新的素材版本替代。
- 隐藏的场景对象和原始 PSD 中无效/隐藏的制作层不作为本次可见作品的制作内容；原始分层资料仍保留，不修改源文件。
- 前景分层缺失、颜色与轮廓版本不一致、元素编号与累计图数量不一致、图像无法读取时，停止导出并提示具体问题，不下载缺页或错层的 PDF。
- 空作品或仅有 UI 白底时，不输出空白制作文件。
- 导出处理中避免重复提交；失败后允许重试，保留保存作品与用户选择，不修改原图、不创建替代素材。
- 导出成功下载一个 PDF，文件名沿用 `<作品名>-彩色裁片图纸.pdf`，过滤不合法的文件名字符。

## 10. 验收标准

以下是功能验收要求，不代表每个素材都已完成实物试制。

| 编号 | 场景 | 通过条件 |
| --- | --- | --- |
| EX-01 | 完整导出 | 一个 PDF，顺序为裁片、各元素制作、整体拼装；没有新增封面或长说明页 |
| EX-02 | 多层元素 | 每个有效制作层恰好对应一步；每步累计保留先前层，新增编号可回查裁片页 |
| EX-03 | 离散配件与镂空 | 不漏小配件、不填真实孔洞；同层共用编号、保留相对位置 |
| EX-04 | 换色和变换 | 保存后换色、旋转、镜像、缩放和移动能正确反映到裁片及步骤图；不读取错版本 |
| EX-05 | 多个实例 | 同一素材放两次，分别编号与制作；整体拼装位置和数量正确 |
| EX-06 | 背景两种模式 | 显示背景时导出背景层与制作步骤；隐藏背景时导出完整彩图而不虚构内部层；两者比例一致 |
| EX-07 | 没有真实背景 | 不出现 UI 白底裁片或空背景编号，整体从首个元素开始 |
| EX-08 | 一本书/A4 上限 | 不再因背景超过旧排版区域而报错；最大适配一张 A4，保持比例，不拉伸、不裁切、不跨页拆单层 |
| EX-09 | 节约纸张 | 不按颜色强制分页；小裁片可利用已有空位；步骤图每页多步且无编号或图片遮挡 |
| EX-10 | 图层多、自动续页 | 续页后无漏步或重复步骤，元素标识可追溯；整体拼装最后一图与保存作品一致 |
| EX-11 | UI 不受影响 | 导出页仍为原有横屏裁片预览，不显示步骤图、A4 纸面或多余说明栏 |
| EX-12 | 缺失或不匹配的数据 | 明确失败，不静默漏层、不下载不完整结果、不启动未授权的拆分处理 |

## 11. 当前实现与验证边界

- 已实现：三段式 PDF、两级编号、累计叠放图、紧凑步骤排版、两种背景模式、统一比例、最大 A4 适配，以及步骤图仅在最终导出中出现。
- 实际端到端验收：使用当前春节 PSD 作品，分别验证背景拆层与整图两种模式，通过实际导出入口生成 PDF，并渲染检查。
- 程序测试已覆盖：不同制作层数量、步骤续页、离散配件、无真实背景、编号一致性，以及横向/纵向/正方形的 A4 适配等情形。
- 尚不能据此宣称：所有主题和任意外部 PSD 都已验证、所有细节均适合手工裁剪，或所有打印机都能正确满幅输出。后续素材接入与实物试制需要独立验收。
