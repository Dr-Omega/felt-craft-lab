| 用户操作 | 实际接入及约束 |
| --- | --- |
| 在画布添加图片、语音生图、按层换色 | 保留原 Canvas、浮动编辑框与个人素材版本。没有另建换色页。 |
| 保存并讲故事／保存并展示 | 先保存成功，再按 projectId 重新读取已保存作品后跳转；保存失败留在画布。 |
| 草稿完成 | 草稿与新作品在同一事务中迁移，失败保留草稿；不留下旧的“继续制作”副本。 |
| 作品重新编辑保存 | 更新同一作品及关联故事的图片；不擅自改写故事文字、确认时间或原音频。 |
| 故事卡 | 接入已有正式 SXY 页面、录音暂停继续、ASR/整理、确认、补录、播放和重开；待确认内容不覆盖正式故事。 |
| 展示与展开 | 使用此作品的元素顺序、变换、固定素材版本及实际拆分层；不读取无关的“最近任务”充当作品。未拆分元素明确显示为完整元素。 |
| 旋转／缩放后展示 | 元素内部先按原始分辨率合成，再应用画布变换，避免逐层插值产生假缝。 |
| 图层记录损坏 | 对照固定版本 PNG 复合结果；来源、颜色或尺寸不一致明确拒绝，不显示替代样例。 |
| 首页 3D 按钮 | 先选择具体保存作品，再进入展示。算法调试页保留为独立“拆分工具”。 |

## 2026-10-08 任务生命周期增量

- 确认生成图片或上传图片后立即准备图层；主进程绑定用户、作品、元素版本、实际输入字节、前景模式和运行实现摘要。同图拖动、保存、离开再返回不会重新计算。不同元素/版本不会串用结果。
- 单个应用进程串行运行，最多保留 20 个等待任务。前一个失败也会推进后一个；连续确认同一输入不重复启动。
- 任务输入及状态写入 userData/fabrication-jobs；全局“图片处理”入口跨页面可见。完成后编辑原元素可加载实际图层。失败只有显式重试才创建新任务，旧日志保留。
- 应用关闭会终止当前 worker；重启后中断/排队记录标明“未完成，需重试”，从保留原图重新开始，不冒充断点续算或后台常驻服务。新请求优先匹配最新任务时间而非 UUID 目录顺序。
- 不再以“有任意透明像素”推断已去背景。上传默认 BiRefNet General；调用方须明确确认已有前景才使用 embedded-alpha。AI 生成图片仍默认去背景。
- 打包版不再无条件禁用，改为校验可配置的外部算法运行目录与环境；**未将 Python、模型和算法树自动打进安装包，未完成安装器端到端验收**。
