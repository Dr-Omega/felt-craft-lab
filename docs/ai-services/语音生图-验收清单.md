# 语音生图 · 产品验收清单（P6）

**分支：** `feature/image-generation/creation-intent-core`  
**页面：** Electron「生成作品」（`CreateAssetPage`）  
**Gateway：** `http://127.0.0.1:8788`  
**角色：** 生图链路负责人  
**暂不验收：** 自训 LoRA、教学解锁、自动分层、换色、打印  

勾选：本地测过打 `[x]`，未测保持 `[ ]`。

---

## 0. 启动前置

- [ ] Flask 已起：`GET /api/health` → `ok: true`
- [ ] Electron `npm run dev` 可打开「生成作品」
- [ ] `IMAGE_PROVIDER` 已知（推荐先 `mock` 跑通，再试 `wan_dashscope` / `sd_local`）
- [ ] 本机麦克风权限可用（语音项）；无麦可用打字代替

---

## A. 引导与儿童文案

- [ ] 首次进入有 3 步「怎么用」引导，可「跳过」或点完「知道了」
- [ ] 跳过后再进页默认不弹；点「怎么用」可重开
- [ ] 页面**不展示**原始「画图说明 / 不要出现」等 prompt 原文
- [ ] 质量 FAIL 时文案说明「只是提醒」，仍可进编辑器

---

## B. 方案卡（P1）

- [ ] 有内容后出现六栏：画谁 / 在做什么 / 颜色 / 必须有 / 不要 / 场景
- [ ] 空栏显示「还没说」
- [ ] 当前追问栏有「正在问这栏」标记
- [ ] 可点「你来定」跳过当前追问（在追问阶段）

---

## C. 说话 / 打字 → 补句（P2）

### 打字

- [ ] 输入「黑白熊猫抱着红色皮球」→ 方案卡主体/动作/颜色有合理填充
- [ ] 追问颜色时只答「坐着」→ **不应**整句塞进颜色栏
- [ ] 补句「不要真实毛发」→「不要」栏有内容
- [ ] 补句场景/必须有后，对应栏更新

### 语音（有麦时）

- [ ] 「开始说话」→ 说完再按 → 出现识别文字并进入方案
- [ ] 空识别 / 失败有温和提示，不崩溃
- [ ] 识别成功后与打字同一套方案卡逻辑

---

## D. 确认出图

- [ ] 方案够完整时出现「就这样画」
- [ ] 点击后进入「请稍等…」/ 画图中提示，最终出现预览图
- [ ] **Mock：** 预览有棋盘格底，主体四周可透出格子（透明 PNG）
- [ ] 有质量条（PASS / WARN / FAIL 之一）与简短中文说明
- [ ] 失败时出现错误文案 +「再试一次」（可恢复）

---

## E. 再画一张 / 重新说

- [ ] 「再画一张」保留方案，换一张预览（mock 也可能因同 prompt 相近，以不丢方案为准）
- [ ] 「重新说」清空会话，回到初始输入

---

## F. 去编辑器装饰

- [ ] 「去编辑器装饰」进入编辑器，核心图案已是刚接受的个人素材
- [ ] FAIL 质量仍可进入（advisory）
- [ ] 图案透明底在编辑器叠贴纸时合理（不整块白底挡贴纸）

---
