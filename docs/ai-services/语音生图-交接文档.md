## 1. 一句话现状

> **产品意图链路与 SD+LoRA 代码接线已完成；当前默认出图常为通义万相。接手后只需：训好/放好 LoRA → 启动本机 WebUI → 切 `IMAGE_PROVIDER=sd_local` → 按验收清单测通，即可收尾本模块。不必重写生图业务代码。**

## 2. 目标 vs 实现（避免误解）

| 项 | 说明 |
|----|------|
| **组内目标** | 生图用 **Stable Diffusion + LoRA** 锁不织布扁平画风 |
| **当前代码** | 出图为 **可切换 Provider**：`mock` / `wan_dashscope`（万相）/ `sd_local`（A1111 + LoRA） |
| **为何像「和 PRD 不一样」** | 意图、方案卡、儿童 UI、抠图、进编辑器是共用链路；云端万相是 **无本机 SD/无权重时的过渡**；SD+LoRA 已接好但 **未切成默认运行态** |
| **接手要不要大改** | **不要重做链路**；改 `.env` + 本机环境即可 |

## 3. 产品链路（已实现）

```text
说话 / 打字
  → ASR（可选）→ Creation Intent 解析（本地规则 + DeepSeek，可回退）
  → 六栏方案卡 + 追问 /「你来定」/ skip（没有、随便…）
  →「就这样画」→ Canonical Prompt（程序编译，不写死 Provider）
  → Gateway /api/image/generate（mock | wan | sd_local）
  → Pillow 抠透明底 + 质量提醒（FAIL 仍可进编辑器）
  → 临时 Preview →「去编辑器装饰」→ PersonalAsset 入库
```

**页面：** `src/renderer/src/pages/CreateAssetPage.vue`  
**意图核心：** `src/shared/creation-intent/`、`src/main/creation-intent/`  
**出图：** `backend/services/image_service.py` + `backend/providers/image/`

## 5. 接手待办（按优先级）

### P0 · 切到 SD+LoRA（本模块收尾关键）

1. 安装并启动 [Automatic1111](https://github.com/AUTOMATIC1111/stable-diffusion-webui)：`webui.bat --api --listen`（默认 `http://127.0.0.1:7860`）
2. 准备 **SD 1.5** 卡通/贴纸底模 + LoRA：
   - 组员自训：`xxx.safetensors` → `models/Lora/`
   - 或暂用社区 flat/sticker LoRA（见 [sd-local-lora.md](./sd-local-lora.md)「暂无自训权重时」）
3. 编辑本机 `backend/.env`（**勿提交**）：

```env
IMAGE_PROVIDER=sd_local
SD_LOCAL_BASE_URL=http://127.0.0.1:7860
SD_LOCAL_LORA_NAME=<文件名不含扩展名>
SD_LOCAL_LORA_WEIGHT=0.7
```

4. 重启 Flask → 打开 Electron「生成作品」→ 打字完整句 →「就这样画」→ 看棋盘格透明预览 →「去编辑器装饰」
5. 复跑：

```text
cd backend
.venv\Scripts\python.exe tools\smoke_image_providers.py --also-sd-local
```

### P1 · 统一人工验收

按 [语音生图-验收清单.md](./语音生图-验收清单.md) 勾选 UI 项（引导、方案卡、再画一张、进编辑器等）。

### P2 · 可选

- 若短期无 GPU：可继续 `IMAGE_PROVIDER=wan_dashscope` 演示产品，**但画风无法用自训 LoRA**
- Background 角色、分层等：见进度清单「明确不做 / Background 已知问题」，**另开任务**，勿混进本交接
