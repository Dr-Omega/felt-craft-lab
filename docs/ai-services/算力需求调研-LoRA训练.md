# 不织布风格 LoRA · 算力需求调研

**项目：** Felt Craft Lab（语音生图 / 本地 SD+LoRA）  
**文档版本：** V1.0  
**日期：** 2026-08-20  
**用途：** 组内选型、向指导教师申请学校云算力、比赛/课程调研材料  
**范围：** 仅「画风锁定用 LoRA 训练与推理」的算力；不含 ASR / DeepSeek / 通义万相按次计费的日常开发额度

---

## 一、调研背景与要回答的问题

本产品希望用 **LoRA** 把文生图结果约束到「扁平卡通、色块清楚、适合不织布裁剪」的统一画风。仓库已接入本地推理路径（`IMAGE_PROVIDER=sd_local`，见 [sd-local-lora.md](./sd-local-lora.md)），但**尚无自有风格 LoRA 权重文件**。

本调研要回答：

1. 训一个可用的风格 LoRA，**算力从哪里来**？  
2. **Liblib 云端训练**、**学校云 GPU**、**个人电脑本地训练** 各自贵不贵、难不难？  
3. 课程项目阶段，**推荐哪条路径**？向老师申请资源时要说清什么？

---

## 二、算力需求拆成两块

| 阶段 | 做什么 | 算力强度 | 频率 |
|------|--------|----------|------|
| **A. 训练（Train）** | 用 20～50 张参考图微调 LoRA | **高、短时**（约 0.5～2 小时/次） | 前期试 1～3 次，后期偶尔再训 |
| **B. 推理（Infer）** | 儿童确认方案后出图（本机 A1111 / 或继续万相） | **中、按次** | Demo / 日常联调，每天可能几十张 |

**结论：** 真正「缺算力」的主要是 **A 训练**；**B 推理**在有一块消费级 NVIDIA 显卡（建议 ≥8GB 显存）时本机即可，也可用通义万相 API 暂代。

---

## 三、方案对比总表

| 维度 | 方案 1：Liblib 云端训 | 方案 2：学校云 GPU | 方案 3：个人普通电脑 |
|------|----------------------|--------------------|----------------------|
| 训练算力谁出 | Liblib 平台 | 学校实验室 / 超算 | 本机显卡 |
| 本机硬件要求 | 能上网即可 | 能 SSH / 远程桌面即可 | 最好 NVIDIA ≥8GB 显存 |
| 费用形态 | 积分 / 会员 | 多为课程免费额度 | 电费；无合适显卡则不可行 |
| 单次训练成本（粗估） | 约 50～300 积分（约数元～二三十元量级） | 通常 **0 元现金**（占配额） | 有卡则近 0；无卡则训不动 |
| 上手难度 | 低（网页上传） | 中（环境、账号、排队） | 中高（装 WebUI / kohya） |
| 权重归属 | 可下载 `.safetensors` | 完全自管 | 完全自管 |
| 适合写进报告 | 「使用国内云平台完成风格微调」 | 「依托学校算力自主训练」 | 「本地可复现训练流水线」 |
| 推荐优先级（本阶段） | **首选试跑** | **正式迭代 / 答辩加分** | 有显卡再考虑 |

> 积分单价与会员档位以 [Liblib 会员中心](https://www.liblib.art/viphome)、[积分明细](https://www.liblib.art/calculation) 实时页面为准；下表数字为公开资料与社区经验的**量级估算**，提交任务前以平台预扣积分为准。

## 四、方案 1：Liblib 云端训练（详细）

### 4.1 机制

- 用户上传训练集 → 平台调度 GPU → 产出 LoRA → 网页内测或**下载权重**。  
- **训练不算在用户电脑上跑**；截图中的「训练我的LoRA」即此入口。  
- 日常「文生图」另计积分（例如约 1 积分/张），与「训练」扣费规则不同。

### 4.2 费用与积分（调研口径）

| 项目 | 说明 |
|------|------|
| 每日登录赠送 | 常见为少量免费积分（如约 20/天），**当日有效、不可囤** |
| 训练一次 | 社区/第三方整理量级约 **50～300 积分/次**（随底模、张数、轮次变化；XL 往往高于 1.5） |
| 会员 | 月费档提供更多积分与训练相关权益；是否强制会员以训练页提示为准 |
| Demo 预算建议 | 预留 **可完成 2～3 次完整训练 + 若干试图** 的积分（避免一次失败就没额度） |

### 4.3 数据与时间

| 项 | 建议 |
|----|------|
| 图片数量 | 风格 LoRA：**20～50 张**同风格、色块清楚 |
| 分辨率 | 尽量正方形，如 768×768 或 1024×1024 |
| 耗时 | 约 **30～90 分钟**/次（平台负载会影响） |

### 4.4 优缺点

**优点：** 不依赖个人显卡；流程短；适合两周内出 Demo 权重。  
**缺点：** 依赖平台积分政策；高级参数不如自建环境自由；需注意素材与生成物的平台条款。

### 4.5 与本仓库对接

下载 `.safetensors` → 放入本机 Automatic1111 `models/Lora/` → `backend/.env`：

```env
IMAGE_PROVIDER=sd_local
SD_LOCAL_LORA_NAME=<文件名不含扩展名>
SD_LOCAL_LORA_WEIGHT=0.8
```

详见 [sd-local-lora.md](./sd-local-lora.md)。

## 五、方案 2：学校云算力（详细）

### 5.1 适用场景

- 需要**多次迭代**训练（换数据集、调 epoch、对比多个 LoRA）。  
- 答辩希望强调「自主可控 / 依托高校算力」。  
- 组内无人有合适独显，又不想长期依赖商业平台积分。

### 5.2 建议向老师申请的规格（最低可用）

| 项 | 最低建议 | 更舒适 |
|----|----------|--------|
| GPU | 单卡 NVIDIA，显存 **≥16GB**（可训 SD1.5 LoRA） | 24GB（SDXL / 更大 batch） |
| 系统 | Linux + CUDA 驱动 | 已装好 Docker / Conda 更佳 |
| 存储 | ≥50GB 可用（底模 + 数据集 + 输出） | ≥100GB |
| 时长 | 连续可用 **4～8 小时**/次训练窗口 | 按周预约若干次 |
| 权限 | 能安装 Python 包或使用容器 | 能开端口测 A1111 API（可选） |

### 5.3 在学校机器上建议跑的软件栈

1. Stable Diffusion 底模（优先 **SD 1.5 卡通/插画系**，与本地推理对齐）  
2. 训练工具：kohya_ss / sd-scripts 或学校已有的训练镜像  
3. （可选）Automatic1111 WebUI `--api`，与项目 `sd_local` 联调  

### 5.4 优缺点

**优点：** 现金成本低；可写进课程报告；数据与权重完全自管。  
**缺点：** 申请与排队成本；环境配置耗时；需要有人会基本 Linux/CUDA。

### 5.5 向老师沟通时可附的一句话

> 我们只需要短期 GPU 做 **LoRA 微调（约 20～50 张图，每次约 1 小时级）**，不是长期跑大模型训练；训完权重放回学生本机 WebUI，接入已有 Electron 应用即可。

## 六、方案 3：个人普通电脑本地训练（详细）

| 条件 | 判断 |
|------|------|
| 有 NVIDIA 独显且显存 **≥8GB** | 可尝试训 **SD1.5 小 LoRA**（分辨率与 batch 要保守） |
| 仅核显 / 集显 / 苹果统一内存未专项配置 | **不建议**作为主训练路径 |
| 只有 CPU | 训练时间过长，课程周期内不现实 |

**结论：** 「普通电脑」**可以**完成 Liblib 上的云端训练操作，但**不等于**能在本机完成 GPU 训练。

## 七、推荐路径（本项目）

### 7.1 阶段建议

```text
第 1 周：整理 20～40 张不织布风格参考图
    → Liblib 云端训 1～2 个 LoRA（快速验证画风）
    → 下载权重接到 sd_local，产品链路联调

第 2 周（可选）：若效果不够或要答辩加分
    → 向老师申请学校云 GPU 做 1～2 轮正式迭代
    → 固定触发词、权重与底模版本写入交付说明
```

### 7.2 费用粗算（Demo 级，仅供预算讨论）

| 科目 | 粗估 |
|------|------|
| Liblib 训练 2 次 + 试图若干 | 约数十元量级（视会员/充值；以平台为准） |
| 学校云 GPU | 通常 0 现金（占教学配额） |
| 本机推理电费 | 可忽略 |
| 通义万相（无 LoRA 时的过渡） | 按张计费，与本调研「训练算力」分开记账 |

### 7.3 风险与对策

| 风险 | 对策 |
|------|------|
| 免费积分不够训一次 | 小额充值或短期会员；先减张数做小实验 |
| 训出来过拟合 / 色偏 | 统一裁剪与风格；加正则图；降权重（0.6～0.8） |
| LoRA 与本地底模不匹配 | 训练时底模族与本机 Checkpoint **同一代**（优先 SD1.5） |
| 学校机器排队 | 提前预约；Liblib 保底出第一版权重 |

## 八、训练集最低规格（算力申请附件）

为避免「有算力但训废」，申请资源或上 Liblib 前应满足：

| 项 | 最低标准 |
|----|----------|
| 数量 | ≥20 张（推荐 30～40） |
| 风格 | 扁平、大色块、少渐变、少毛发、轮廓清楚 |
| 内容 | 可含多种题材（动物、器物），但画风一致 |
| 格式 | PNG/JPG，尽量正方形 |
| 版权 | 组内自制或已获权使用的素材；勿直接抓取侵权图 |

## 九、结论（可直接写进汇报）

1. **训练算力**是风格 LoRA 的关键瓶颈；**推理算力**可用本机 GPU 或继续用云端文生图 API 过渡。  
2. **Liblib** 适合「无本地显卡也能训」的第一版，费用以积分为单位，单次通常为小几十元量级内可控（以平台预扣为准）。  
3. **学校云算力**不是必须，但若老师可提供 ≥16GB 显存短期 GPU，更利于多次迭代与「自主训练」表述。  
4. **普通家用电脑**足以操作云端训练与下载权重；没有合适独显时，不应把「本机训练」写进必做路径。  
5. 推荐：**Liblib 出第一版权重 → 接入本仓库 `sd_local` → 有条件再用学校算力精修。**
