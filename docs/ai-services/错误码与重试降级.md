# 错误码、重试与降级规则（第 10 步 / 规范第 13 条）

面向：**组长维护**，**SXY 按本文做前端提示**。  
在线契约（后端跑着时可打开）：

| 地址 | 内容 |
|------|------|
| `/api/asr/contract` | ASR 字段 + 错误码 |
| `/api/qa/contract` | QA 字段 + 错误码 |
| `/api/tts/contract` | TTS 字段 + 错误码 |
| `/api/ops/rules` | 本文规则的机器可读摘要 |

---

## 1. `.env` 怎么配（不要提交真实密钥）

1. 复制 `backend/.env.example` → `backend/.env`
2. 只在本机填写 Key
3. GitHub Desktop / git 里确认 **没有** `.env`

常用变量见 `.env.example` 注释。切换 Mock（无密钥联调）：

```env
QWEN_ASR_PROVIDER=mock
QA_PROVIDER=mock
TTS_PROVIDER=mock
```

---

## 2. 通用错误形状

失败时后端尽量返回：

```json
{
  "ok": false,
  "error": {
    "code": "ASR_NETWORK_ERROR",
    "message": "给用户看的中文说明",
    "retryable": true
  },
  "latencyMs": 0
}
```

SXY 规则：

| `retryable` | 页面建议 |
|-------------|---------|
| `true` | 显示「再试一次」按钮，可自动重试 1 次 |
| `false` | 只提示原因，不要死循环重试 |

## 3. ASR（语音识别）

### 3.1 产品降级（硬规则）

| 情况 | 必须怎么做 |
|------|------------|
| `result.empty === true` | **禁止**调用 QA；提示「没听清，请再说一次」；保留文字输入 |
| 麦克风权限拒绝 | 保留文字提问入口 |
| ASR 失败且 `retryable=true` | 可重录 / 再识别 1～2 次 |
| ASR 持续失败 | 降级为**纯文字提问**，不要卡住整页 |
| Provider 升级（realtime/local） | 只改后端；页面不绑死某个模型名 |

### 3.2 错误码（摘要）

| code | retryable | 用户提示方向 |
|------|-----------|--------------|
| `ASR_MISSING_API_KEY` | 否 | 找组长检查 `.env` |
| `ASR_MISSING_AUDIO` | 否 | 录音没传上 |
| `ASR_TIMEOUT` | 是 | 再试一次 |
| `ASR_NETWORK_ERROR` | 是 | 检查网络 |
| `ASR_BAD_RESPONSE` / `ASR_UPSTREAM_ERROR` | 是 | 再试一次 |
| `ASR_PROVIDER_NOT_READY` | 否 | 该通道未开通（占位 Provider） |
| `ASR_EMPTY_TRANSCRIPT` | 是 | 请再说一次 |

延迟验收看：`/api/asr/metrics`（目标 P50≤1.5s，P95≤3s，失败率≤5%）。  
不达标再走规范升级路线：HTTP → Realtime → 本地，**不是第 10 步强制项**。

## 4. QA（DeepSeek 问答）

### 4.1 产品降级

| 情况 | 必须怎么做 |
|------|------------|
| 缺少 `asset` | 不发请求；提示先选中贴纸 |
| `safetyAction=redirect/reject` | 展示返回的温和文案，不要继续追问敏感内容 |
| QA 失败 `retryable=true` | 可重试 1 次；仍失败提示「稍后再问」 |
| QA 不可用 | 页面仍可浏览素材 / 播放**固定介绍语音** |

### 4.2 错误码（摘要）

| code | retryable |
|------|-----------|
| `QA_MISSING_API_KEY` | 否 |
| `QA_MISSING_QUESTION` | 否 |
| `QA_MISSING_ASSET` | 否 |
| `QA_TIMEOUT` | 是 |
| `QA_NETWORK_ERROR` | 是 |
| `QA_UPSTREAM_ERROR` | 是 |
| `QA_REJECTED` | 否 |

---

## 5. TTS（动态语音）

### 5.1 产品降级（硬规则）

| 情况 | 必须怎么做 |
|------|------------|
| TTS 失败 | **`fallback: keep_text_only`**：文字回答照常显示，不弹致命错误 |
| 音频播放失败 | AudioService 吞掉错误，不挡文字 |
| 固定介绍语音 | 优先用 `/fixed-audio/` 快照；不要每次都动态合成 |

### 5.2 错误码（摘要）

| code | retryable |
|------|-----------|
| `TTS_MISSING_API_KEY` / `TTS_MISSING_GROUP_ID` | 否 |
| `TTS_MISSING_TEXT` | 否 |
| `TTS_TIMEOUT` / `TTS_NETWORK_ERROR` / `TTS_UPSTREAM_ERROR` | 是（可静默跳过朗读） |

动态 TTS 使用文本哈希缓存：相同文案会命中缓存，减少费用与等待。

---

## 6. 前端服务层降级

| 服务 | 失败时 |
|------|--------|
| AudioService | 不抛到业务层；文字仍在 |
| AnimationService | 未知 `eventKey` 只打日志；不崩页面 |
| FeltAiClient | 按 `ok` / `retryable` 分支处理 |

---

## 7. 推荐重试次数（SXY）

| 接口 | 自动重试 |
|------|----------|
| ASR | 最多 1 次（用户也可手动再录） |
| QA | 最多 1 次 |
| TTS | **默认不自动重试**；失败直接保留文字 |

间隔建议 500ms～1s，避免连点打爆额度。
