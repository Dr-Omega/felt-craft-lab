## 2. 云服务使用记录

| 服务 | 用途 | 账号侧 | 配置项（`.env`） | 计费注意 |
|------|------|--------|------------------|----------|
| 阿里云百炼 / DashScope · Qwen3-ASR-Flash | 语音转文字 | 组长申请 | `QWEN_ASR_API_KEY` 或 `DASHSCOPE_API_KEY` | 按调用量；联调优先 Mock / smoke-test |
| DeepSeek API | 儿童适龄贴纸问答 | 组长申请 | `DEEPSEEK_API_KEY` | 按 token；注意余额 |
| MiniMax TTS | 动态朗读 + 固定批量快照 | 组长申请 | `MINIMAX_API_KEY` + `MINIMAX_GROUP_ID` | 按字符/次；固定文案用批量+缓存降本 |

### 2.1 安全约定

- Key **只**存在本机 `backend/.env`
- 前端与 GitHub **零密钥**
- 健康检查接口只返回 `set(sk***xx)` 掩码，不回传完整 Key

### 2.2 降本与降级

- 动态 TTS：文本哈希缓存（相同句子不重复计费）
- 固定介绍：批量生成快照，页面播本地/静态文件
- 无密钥或联调：`PROVIDER=mock`
- TTS 失败：保留文字（`keep_text_only`）
