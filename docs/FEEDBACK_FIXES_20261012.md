## 3. 修复后的主要使用顺序

### 创作与故事

标题 → 登录 → 大厅蘑菇/开始创作 → 新画布中央选择框 → 上传图片或语音生图 → 确认图片 → 开始准备分层 → 在完整画面中双击元素 → 编辑 → 选择制作层、换色 → 应用。

分层环境不存在时：原图仍在画布，可以继续拼贴；换色面板明确没有可用结果，维护者可展开查看环境信息、安装后重试。不会把原图冒充已经拆分的图层。

画布底部保存 → “保存，继续画 / 保存并讲故事 / 保存并展示”。故事路径为保存真实作品 → 开始录音 → 完成录音 → 补充 → 生成草稿 → 确认。服务失败不等于生成成功，补充输入保留。恢复旧作品或进入主题任务时不额外弹出新作品选择框。

### 学习与主题解锁

大厅树书架 → 单元/主题 → 背景与贴纸预览 → 进入引导创作 → 按指定步骤摆放和收听 → 检查通过 → 解锁整个主题 → 素材说明/名称音频/介绍音频/问问它。解锁任务仍是独立场景，不复用或覆盖自由作品。

### 个人中心与小熊

- 大厅头像 → 账号 / 作品 / 邮箱 / 商城。账号内可查看余额、转换、同步与冲突；邮箱、商城复用现有服务，不创建第二套余额或奖励逻辑。
- 大厅小熊 → 小熊的家 → 喂食 → 返回大厅。2026-10-13 核对后移除整图滤镜配色、只改名称的角色切换、文字互动及其保存/载入入口：现有房间为合成 PNG，未提供可独立替换的房间图层或角色动画。保留原画比例及后端已有偏好数据，不自动覆盖；喂食仍走真实服务接口。
- 分享入口保持独立，不把个人作品管理与公开分享页混为一页；未更改发布隐私规则。

## 4. 服务部署：不需要改产品规则，但仍需落实

维护者应按 [组长服务交接](TEAM_LEAD_SERVICE_HANDOFF.md) 配置，不将 API key 发到前端或仓库。

1. 所有终端使用有效 HTTPS Gateway；账号服务可用，不代表每个 AI 服务和本地 Python 都可用。
2. 语音识别使用 Qwen/DashScope，素材问答使用 DeepSeek，图片生成使用 Ark/Seedream，故事整理使用 Qwen Story，动态朗读使用 MiniMax。分别核对账号权限、服务配置与真实返回。
3. 截图里的 Mac 需要匹配的算法目录、Python 依赖、BiRefNet 缓存。当前主进程仍启动本地 Python；共享业务服务器不自动变成分层计算服务器。只补 API key 不能修复缺失的本地分层运行目录。
4. 本轮补充 macOS 麦克风用途声明，但未在真实 Mac 安装包验证系统授权、签名及实际设备录音。Windows 的模拟麦克风测试不能替代它。
5. 正式确认“可用”前，至少在组员实际安装包依次运行问答、语音识别、生图、故事整理和一次真实分层换色。本轮未持有组长密钥，未操作组员电脑，不伪报完成。
