## Demo 启动与范围

- 双击根目录 `Start-Felt-Craft-Demo.cmd`（同样需要完成本地配置）。它仅给本次启动设置 `VITE_PROVIDED_PSD_DEMO=1`；不修改 `.env.local` 或正式生成接口。
- Demo 中在“添加图片 → 语音输入生图”打字或录音，发送描述后确认绘画内容，任意非空描述均显示相同福娃；“再画一张”也使用同一原图。使用这张图后保留全部 8 层，可直接换色和导出，不请求意图模型、图片生成、去背景或拆分服务。
- 普通 `Start-Felt-Craft.cmd` / `npm run dev` / `npm run build` 未设置上述开关时仍使用真实图片生成流程。Demo 构建如有需要，应在构建时显式设置该 Vite 开关，不能把固定返回福娃当作正式生成结果。
- 问一问的真实 API 和第一人称规则不变。无新增素材授权声明，使用范围仍须由提供者确认。
- 录音转写、问一问、讲故事等非图片功能不替换为固定结果，仍需要相应后端服务。
- 这批 PSD 不经过算法任务；非 PSD 的普通上传图片沿用已有功能。本次没有接回此前未认可的拆分/简化实验。

## 验收

图纸默认成品长边为 18 cm（此前 8 cm），统一等比放大，可在导出弹窗调整尺寸。预览和 PDF 使用当前图层颜色的实色色块，复合路径按 even-odd 规则留出真实孔洞，裁片描边与编号保留；不是只有黑色轮廓的空心图纸。PDF 不画纸张外边框，A4 预览也不添加纸张描边；裁片自身的边界与页面外框是两回事。白色原材料仍显示为白色并有裁剪边界，不误涂成背景。

图纸只显示色块与两级编号，例如 `2-1` 表示整个场景从下往上的第 2 层元素，其内部制作过程从下往上的第 1 层。同层多个离散色块保留原始相对位置作为一组，只标一次编号，不增加第三个裁片流水号，也不把微小离散点散排成重复编号行。图层组之间保留 6 mm 间距。实际背景占第 1 层编号但不导出为裁片；UI 白底不计入编号。混色排版不会改变这些层序编号，不因颜色或元素不同而强制换页。所有标题、色号、页码、提示语及校准线均已移除，也不再为它们预留页眉页脚空间。

隔离账号数据的真实 Electron 验收覆盖：红包/灯笼换色、任意描述生成福娃、福娃 8 层换色、保存重开继续编辑、展开重建和 A4 PDF。测试摆放仅为验收用，不写入产品预设。保存预览与按层重建逐像素一致；换色前后轮廓一致；无新增算法任务。PDF 仍需按 100% 打印校准并实物试剪，不以软件验收冒充实物制作认证。

## 复现

`uv run scripts/import-provided-psd.py --source <含五份原始文件的目录>`

导入脚本拒绝覆盖已有快照；应在尚未导入本包的检出上复现。Python 依赖只用于开发时提取，应用运行不依赖 PSD 解析库。
