# 按主题解锁：创作画布引导接入

## 规则与实现

解锁单位是主题。锁定素材不能放入自由创作；素材库、画布素材盒和背景选择器提供前往对应主题的入口。
主题页仅做选择、内容预览与已解锁内容浏览，原独立拖放小游戏已移除。

引导任务通过 `openEditor({ guidedTheme, scene })` 进入原 `EditorPage`，复用 `DrawingFrame`、Fabric 与 `EditorSessionService`。
每次任务使用独立 Scene 身份、独立 Main 会话；不写草稿/作品，不将任务素材的临时访问记录写入 AssetAccess。
任务退出后未完成进度不保存，下次重新开始；已完成主题权限保留。

沿用仓库现有 21 关卡/15 主题的素材顺序、目标区域、位置容差和三段讲解。每主题使用现有列表中的首个关卡（同主题的其他背景也随主题解锁），未另创教学内容。
用户逐步添加素材，在真实画布拖动，听完名称/介绍后点击“检查这一步”。贴纸按关卡 placeholder 尺寸等比适配，任务中仅允许移动，不开放自由添加、分层换色、缩放或保存为作品。

Main `guide-step` 验证真实 Scene 合同、用户/主题/快照/背景/尺寸、指定素材集合无遗漏重复、步骤顺序、当前及先前素材的可见状态和实际位置。
旧 `placements` 快捷完成路径被拒绝。全部步骤通过后才签发主题完成记录；原有原子事务一次性保存主题进度及本主题全部背景/贴纸权限，其他主题不变。
讲解播放由 Renderer 真实媒体 ended 事件驱动，Main 检查回传的音频列表与指定步骤匹配；这不是对恶意修改客户端的防作弊证明，也不证明用户实际听懂。

自由创作中前往解锁仍复用现有离开确认；取消保持当前编辑，保存/直接离开后定位该主题。解锁任务本身与已有作品不是同一份 Scene。
已接素材源、历史快照、图层换色及其他既有修改保留；未改算法、冻结文件或正式分支。

## 验证

- `npm run typecheck`：通过。
- `node node_modules/vitest/vitest.mjs run --reporter=dot`：95 文件 / 631 通过 / 0 失败。
- `npm run build`：通过。
- 21 个关卡在 Main 中逐一验证完成与精确主题素材集合；补充错主题、跳过讲解列表、重复/隐藏对象、改动前一步位置、更换 Scene 身份、乱序和旧接口拒绝。
- 适配器回归验证任务尺寸等比适配、非法尺寸拒绝，旧显式位置与默认添加行为不变。
- 真实 Electron UI：锁定素材不能添加 → 前往对应主题 → 原创作画布添加及鼠标拖动三贴纸 → 九段真实打包音频播放 → 错位置拒绝 → 中秋五项权限一起解锁 → 端午中途退出不授权 → 刷新后权限保留 → 月亮可加入自由创作。
- 音频以 8 倍播放速度测试，没有伪造 ended 事件、完成标记或权限；未调用付费服务。
- 1440×900、960×640 截图实际复核。修正过程中发现并解决指定位置贴纸原尺寸过大及引导条被画框遮挡。早期失败/中间截图保留，最终 UI 证据是 `frontend-flow-audit-20261008/guided-theme-04/`。
- 外部可重复 UI 脚本：`node ../frontend-flow-audit-20261008/check-guided-creation.cjs <新的输出目录>`（先 build，使用独立 Electron profile）。
