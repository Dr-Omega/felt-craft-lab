# 录制后文字补充适配器

**任务：** SC-02-04  
**状态：** 已实现，待阶段 2 统一验收  
**范围：** 将已有完整录音后的手动文字补充转换为统一故事处理请求；不调用转写／整理服务，也不写入正式故事卡。

---

## 输入与输出

适配器接收作品 ID、非空文字和已有完整录音的应用内 `audio` 资源引用，返回：

```ts
{
  workId,
  kind: 'manual_text',
  text,
  baseOriginalAudioRef
}
```

- 输入文字去除首尾空白后不能为空；否则返回 `EMPTY_INPUT`。
- 输入必须携带当前作品的完整录音输入对象；其 `kind` 仅可为 `initial_full_recording` 或 `full_rerecording`，且其中音频引用必须是 `felt-resource://audio/...`，不能是 `blob:` URL、系统路径或远程链接。
- 输出中不包含新的 `audioRef` 或 `durationMs`，因此手动文字不会被误认为新的完整录音。
- 适配器在运行时拒绝 `partial_supplement`、作品不匹配和无效音频引用；引用存在性由保存链路与后续故事处理服务验证。
