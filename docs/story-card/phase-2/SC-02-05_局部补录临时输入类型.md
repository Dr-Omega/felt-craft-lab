# 局部补录临时输入类型

**任务：** SC-02-05  
**状态：** 已实现，待阶段 2 统一验收  
**范围：** 定义局部补录的临时故事处理输入；不保存局部音频、不处理故事文本、不替换正式原始音频。

---

## 类型边界

局部补录使用独立的 `TemporaryPartialSupplementInput`：

```ts
{
  workId,
  kind: 'partial_supplement',
  audioRef,
  durationMs
}
```

- `kind` 固定为 `partial_supplement`；完整录音只能使用 `initial_full_recording` 或 `full_rerecording`。
- `audioRef` 必须是应用内 `felt-resource://audio/...` 引用。
- `durationMs` 必须为正整数，且不超过 `300000` ms。
- 此类型没有 `baseOriginalAudioRef`，也没有任何“替换原始音频”的字段；后续确认流程必须据 `kind` 禁止它替换正式 `originalAudioRef`。
