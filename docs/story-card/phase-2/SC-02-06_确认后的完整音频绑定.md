# 确认后的完整音频绑定

**任务：** SC-02-06  
**状态：** 已实现，待阶段 2 统一验收  
**范围：** 仅在确认服务被调用时，将完整录音引用写入正式故事卡；不实现确认界面、候选稿编辑或临时文件清理。

---

## 绑定规则

- 服务先将 `temp/` 下的完整录音移动至 `confirmed/`，再将该受保护引用写入正式故事卡。
- 仅 `initial_full_recording` 与 `full_rerecording` 可作为正式 `originalAudioRef`。
- 作品 ID 必须一致，确认后的录音引用必须为 `dynamic/story-card/confirmed/` 下的应用内 `audio` 资源。
- 同一 `workId` 尚无正式卡时调用 `create`；已有正式卡时调用 `replace`。
- `partial_supplement` 在运行时被拒绝，不能写入或替换正式 `originalAudioRef`。

本服务是阶段 2 的后端确认边界；孩子／家长点击“确认这就是我的故事”的界面和编辑流程由阶段 4、5 接入。
