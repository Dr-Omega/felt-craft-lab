# 五分钟录音上限

**任务：** SC-02-02  
**状态：** 已实现，待阶段 2 统一验收  
**范围：** 对录音会话累计时长进行限制；不实现真实计时器、麦克风接入或音频保存。

---

## 规则

- 完整录音与完整重录的最大时长均为 `300000` ms（5 分钟）。
- 只在 `recording` 或 `rerecording` 状态累计实际录制时长；暂停时不可继续累计。
- 累计值达到或超过上限时，时长固定为 `300000` ms，会话自动转为 `ended`。
- 到达上限时，`addRecordedDuration()` 返回 `{ status: 'limit_reached', durationMs: 300000 }`，供后续录音控件停止继续接收音频。
- 执行 `rerecord` 时，新的完整录音从 `0` ms 开始计时。

## 数据边界

本任务只维护内存中的会话时长。阶段 2 后续任务负责把结束录音保存为临时资源，并在生成故事处理请求时再次校验 `durationMs`。
