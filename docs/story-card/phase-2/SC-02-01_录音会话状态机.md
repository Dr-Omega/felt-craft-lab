# 录音会话状态机

**任务：** SC-02-01  
**状态：** 已实现，待阶段 2 统一验收  
**范围：** 仅管理录音控件的状态与合法跳转；不录制音频、不校验时长、不保存临时文件。

---

## 状态

| 状态 | 含义 |
| --- | --- |
| `not_started` | 尚未开始录音。 |
| `recording` | 正在录制首次完整故事。 |
| `paused` | 已暂停，尚可恢复、结束或重录。 |
| `ended` | 当前录音已结束。 |
| `rerecording` | 已放弃当前片段，正在录制新的完整故事。 |

## 合法跳转

| 当前状态 | 操作 | 下个状态 |
| --- | --- | --- |
| `not_started` | `start` | `recording` |
| `recording` | `pause` / `end` / `rerecord` | `paused` / `ended` / `rerecording` |
| `paused` | `resume` / `end` / `rerecord` | `recording` / `ended` / `rerecording` |
| `ended` | `rerecord` | `rerecording` |
| `rerecording` | `pause` / `end` | `paused` / `ended` |

其他跳转会抛出 `RecordingSessionTransitionError`，并携带当前状态与尝试的操作，供后续测试界面提示。

## 本任务假设

“重录”会立刻开始一段新的完整录音，因此使用独立的 `rerecording` 状态。暂停后的恢复统一进入 `recording`；此状态机不决定后续音频应使用 `initial_full_recording` 还是 `full_rerecording`，该输入资产语义由后续任务处理。
