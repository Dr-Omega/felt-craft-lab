## 1. 必须修复

### RF-01：保护已确认的正式原始音频

**优先级：** P0（阻塞阶段 2 通过）

**问题：** 完整录音确认后仍位于 `dynamic/story-card` 临时路径；当前临时删除接口按路径前缀删除，无法识别该引用已成为正式 `originalAudioRef`，可能误删正式音频。

**推荐修复方案：** 将路径按生命周期分区。

- 未确认录音保存为 `felt-resource://audio/dynamic/story-card/temp/<uuid>.webm`；
- 完整录音确认时原子移动为 `felt-resource://audio/dynamic/story-card/confirmed/<uuid>.webm`，并将新引用写入正式故事卡；
- 临时删除接口只允许删除 `dynamic/story-card/temp/` 下的文件；
- 局部补录同样只能位于 `temp/`，确认后删除；
- 旧的未确认完整录音仅在新替代录音已保存成功后删除。

**人工确认节点：** 以上“临时／已确认”路径分区会改变完整录音确认时的资源引用。实施前需项目组确认采用该方案；未确认不得修改存储路径或删除逻辑。

**影响范围：**

- Main 临时音频写入、移动与删除实现；
- Main／Preload／Renderer 的音频资源接口；
- 完整录音确认绑定服务；
- 临时清理服务；
- 录音存储、确认绑定、清理与组合流程测试；
- 阶段 2 的任务文档、验收记录和修复记录。

**不涉及：** 语音识别、故事整理、正式 UI、个人空间、局部补录文本处理规则。

**验收标准：**

1. 确认后的 `originalAudioRef` 必须位于 `confirmed/` 路径；
2. 任何临时删除接口不得删除 `confirmed/` 路径、固定素材音频或系统路径；
3. 完整重录成功后只删除旧 `temp/` 完整录音；
4. 取消流程与局部补录确认只能删除 `temp/` 文件；
5. 自动化测试覆盖上述正向、拒绝与删除失败重试分支；
6. 全量测试和三组 TypeScript 检查通过。

**完成记录：** 已采用经人工确认的路径分区。完整录音先写入 `temp/`，调用“确认这就是我的故事”对应的确认服务时原子移动到 `confirmed/`，再将新引用写入正式故事卡；临时删除接口拒绝 `confirmed/` 引用。局部补录仍保留在 `temp/`。

**验证结果：**

- 定向回归：`vitest run tests/story-card/temporary-recording-storage.test.ts tests/story-card/confirmed-full-recording.service.test.ts tests/story-card/recording-input-assets.workflow.test.ts`，3 个文件、9 项测试通过；
- 全量回归：`vitest run`，40 个文件、306 项测试通过；
- 类型检查：`tsc --noEmit -p tsconfig.node.json`、`tsc --noEmit -p tsconfig.test.json`、`vue-tsc --noEmit -p tsconfig.web.json` 均通过。

### RF-04：手动文字补充必须绑定完整录音

**优先级：** P1（阻塞阶段 2 通过）

**问题：** 手动文字补充适配器此前只接收裸音频引用，虽然字段名是 `fullRecordingAudioRef`，运行时却无法拒绝局部补录音频，不满足“仅在已有完整录音时生成请求”的验收条件。

**修复方案：** 改为接收当前作品的 `TemporaryFullRecordingInput`；运行时仅接受 `initial_full_recording` 或 `full_rerecording`，校验录音与当前 `workId` 一致，并继续校验应用内音频引用。

**影响范围：** 手动文字补充适配器、其单元测试、组合流程测试与 SC-02-04 文档；不修改音频存储、正式音频绑定、故事处理或 UI。

**验收标准：**

1. 初始完整录音和完整重录均可生成 `manual_text` 请求；
2. `partial_supplement` 录音和不同作品的完整录音均被拒绝；
3. 输出仍不包含新的音频或时长字段；
4. 相关测试和三组 TypeScript 检查通过。

**完成记录与验证结果：** 适配器现要求完整录音输入对象并执行 `kind`、`workId` 与应用内音频引用校验。定向验证 `vitest run tests/story-card/manual-text-input.adapter.test.ts tests/story-card/recording-input-assets.workflow.test.ts`：2 个文件、6 项通过；全量回归 `vitest run`：40 个文件、308 项通过；`tsc --noEmit -p tsconfig.node.json`、`tsc --noEmit -p tsconfig.test.json` 与 `vue-tsc --noEmit -p tsconfig.web.json` 均通过。
