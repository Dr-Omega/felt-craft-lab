# 临时录音清理策略

**任务：** SC-02-07  
**状态：** 已实现，待阶段 2 统一验收  
**人工确认：** 已确认本文件中的重录、取消与确认后的清理时机。  
**范围：** 清理故事卡临时录音；不删除正式故事卡的原始完整音频。

---

## 清理规则

| 事件 | 删除内容 | 保留内容 |
| --- | --- | --- |
| 完整重录 | 新录音成功保存后删除旧的未确认完整录音。 | 新完整录音。 |
| 取消流程 | 删除本流程的未确认完整录音及局部补录音。 | 无。 |
| 完整录音确认 | 删除遗留局部补录音。 | 已绑定为正式 `originalAudioRef` 的完整录音。 |
| 局部补录确认 | 删除该局部补录音。 | 原正式完整音频。 |

## 实现边界

- Main 删除接口只接受 `felt-resource://audio/dynamic/story-card/temp/...` 引用，拒绝已确认音频、系统路径、固定素材音频和其他动态音频。
- 删除失败不会中断已确认卡；清理服务在 `failedRefs` 返回失败引用，调用方可在后续重试。
- 完整重录的旧文件只在替代录音成功保存后才进入删除流程。
