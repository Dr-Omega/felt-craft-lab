# SC-05-02 录音与文字补充测试控件

**任务：** SC-05-02
**状态：** 已完成
**范围：** 在故事卡测试入口中接入浏览器麦克风录音、开始／暂停／继续／结束／重录控件，以及录制后的手动文字补充控件；不实现音频播放、ASR、故事整理、候选稿或正式确认。

## 实现内容

- 复用阶段 2 的 `RecordingSession` 合法状态机，页面显示当前状态和累计时长。
- 在 Electron 中通过浏览器 `MediaRecorder` 录制 WebM，结束后调用既有临时音频桥接保存为应用内资源引用。
- 重录只在新完整录音成功保存后删除旧临时录音，避免先删旧录音导致丢失。
- 手动补充文本仅在已有完整录音时可提交，并复用既有适配器生成 `manual_text` 请求；其结果不会替换原始音频。

### 人工确认节点

1. 启动应用并打开“故事卡测试”，点击“进入故事卡测试流程”。
2. 点击“开始录音”，在系统提示中允许麦克风权限；确认状态变为 `recording`。
3. 依次点击“暂停录音”“继续录音”“结束录音”，确认状态变化正确，结束后出现临时完整录音引用。
4. 输入一段补充文字并提交，确认出现 `manual_text` 请求提示，且该提示关联上述完整录音引用。
5. 点击“重新录音”，录制并结束另一段音频；确认状态可完成重录，且文字补充仍只关联新的完整录音。
6. 确认测试页可纵向滚动，以查看“录制后文字补充测试”区域和操作结果。
