# SC-05-07 作品修改三种更新测试入口

**任务：** SC-05-07
**状态：** 已完成并通过验收
**范围：** 在阶段 5 测试页面为已确认故事卡提供作品图片更新后的三种选择：保持当前故事、完整重录、局部补录；不接入正式作品编辑页、不新增录音控件、不在本任务中确认或覆盖故事卡。

## 实现内容

- “模拟作品图片更新”使用一张不同的既有素材图片，调用既有图片同步服务后再展示三种选择。
- “保持当前故事”只执行保持动作；图片已经更新，故事正文和完整原始音频不改变。
- “完整重录（Mock）”与“局部补录（Mock）”分别构造对应输入类型，并调用阶段 4 的既有处理流程展示不同标题的临时候选稿，便于人工区分路径。
- 两种候选稿均明确标记为未确认；本任务不会新建／覆盖正式故事卡，也不会保存 Mock 音频。
