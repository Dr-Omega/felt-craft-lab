# SC-05-03 候选故事与补充流程展示

**任务：** SC-05-03
**状态：** 已完成
**范围：** 展示阶段 3 返回的临时候选故事、内容不足问题和补充输入；不提供候选稿编辑、正式确认、保存或真实 AI 服务接入。

## 实现内容

- 使用固定 Mock 展示只读 `ready_for_review` 候选故事，明确标记为未确认。
- 使用短文本 Mock 触发 `needs_more_input`，展示既有服务返回的 3 个儿童友好问题，不展示虚构的故事。
- 可填写补充回答并再次调用相同的手动文字处理入口，验证补充后回到候选故事。
- 测试页不持久化候选稿、第一轮转写或补充文本。

### 人工确认节点

1. 完成一段完整录音后，点击“填入候选故事示例”，提交文字补充测试，再点击“处理为候选故事”。
2. 确认显示只读标题和故事正文，并标记为“临时候选故事（未确认）”；页面没有确认／保存按钮。
3. 点击“填入内容不足示例”，提交文字补充测试，再点击“处理为候选故事”。
4. 确认只显示 3 个补充问题，不显示标题或完整故事。
5. 在“补充回答”中保留预填的 Mock 内容，点击“提交补充并重新整理”；确认重新显示临时候选故事。
