# SC-05-04 编辑与正式确认测试

**任务：** SC-05-04
**状态：** 已完成，验收通过
**范围：** 在测试页编辑候选标题和故事正文，并通过“确认这就是我的故事”创建或覆盖本地测试故事卡；不实现个人空间展示、详情页、音频播放器或云端同步。

## 实现内容

- `ready_for_review` 候选稿自动转换为既有编辑载荷，标题和正文可修改。
- 候选稿明确标识“未确认”，在点击确认前不创建正式故事卡。
- 确认按钮复用阶段 4 正式确认命令：校验标题／正文、提升临时完整音频至受保护引用，并写入本地故事卡仓储。
- 确认后显示“正式故事卡（已确认）”及确认时间；同一作品后续确认会覆盖现有本地测试故事卡。

### 人工确认节点

1. 完成录音并生成“临时候选故事（未确认）”。
2. 修改标题或故事正文，确认页面仍标注为未确认，且未显示正式故事卡结果。
3. 点击“确认这就是我的故事”。
4. 确认原候选编辑区域被“正式故事卡（已确认）”结果替换，标题／正文为修改后的内容，并显示确认时间。
5. 确认页面不再显示候选稿的确认按钮；重复本流程时，同一作品仅覆盖本地测试故事卡。

**验证结果：** 自动验证通过：4 个测试文件、12 项测试通过；Node、测试、Renderer 三组 TypeScript 检查通过。Electron 人工确认通过：候选稿确认后替换为“正式故事卡（已确认）”，显示已保存的标题、正文、确认时间及本地写入提示。
