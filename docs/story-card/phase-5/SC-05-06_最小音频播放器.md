# SC-05-06 最小音频播放器

**任务：** SC-05-06
**状态：** 已完成并通过验收
**范围：** 为已确认故事卡的原始音频加入测试用播放／暂停、当前／总时长和可拖动进度；不修改音频保存、故事卡字段、下载功能或正式 UI 设计。

## 实现内容

- 使用隐藏的 `<audio>` 直接读取正式卡片中的 `originalAudioRef`，页面只呈现一组自定义播放控件。
- 使用单一的大号“播放原始音频／暂停播放”按钮、当前／总时长和可拖动进度条，避免重复控件。
- 为 `felt-resource://` 本地资源协议补充分段读取，使 WebM 音频可以从拖动后的时间点继续播放。
- 页面离开、重新确认或重新读取详情时停止播放并清空播放器状态。

### 人工确认节点

1. 点击“读取已确认故事卡详情”。
2. 点击大号“播放原始音频”按钮，确认可听到刚才录制的内容，按钮变为“暂停播放”。
3. 确认控件显示当前时间与总时长，且总时长大于 `0:00`。
4. 拖动进度条到中间并松开，确认进度不会回到开头，并从新位置继续播放。
5. 点击“暂停播放”，确认声音停止，且页面中没有第二组播放／暂停控件。
