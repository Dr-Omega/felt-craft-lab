# SC-04-01 候选稿编辑载荷

**任务：** SC-04-01
**状态：** 已实现，待阶段 4 统一验收
**范围：** 将可确认候选稿转换为标题与故事正文的临时编辑载荷；不执行正式确认、保存、覆盖或 UI 展示。

## 编辑边界

- 仅 `ready_for_review` 候选稿可生成编辑载荷。
- 载荷仅含 `workId`、`title`、`storyText`，调用方可在内存中修改标题和故事正文。
- 编辑载荷不是正式 `StoryCard`，不包含音频引用、确认时间、图片、第一轮转写或候选稿状态。
- `processing`、`needs_more_input`、`failed` 候选稿返回 `INVALID_ARGUMENT`，不能进入编辑。
- 本任务不校验最终编辑文本，也不写入仓储；这些动作由 `SC-04-02` 及后续任务处理。
