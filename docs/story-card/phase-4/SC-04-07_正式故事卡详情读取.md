# SC-04-07 正式故事卡详情读取

**任务：** SC-04-07
**状态：** 已实现，待阶段 4 统一验收
**范围：** 提供已确认作品故事卡的详情读取接口；不实现详情 UI、音频播放器或中间数据读取。

## 返回边界

详情接口 `getStoryCardDetail(workId, repository)` 只返回以下六个正式字段：

- `workId`
- `artworkImageRef`
- `title`
- `storyText`
- `originalAudioRef`
- `confirmedAt`

接口在读取后按上述白名单重新组装对象，因此第一轮转写、候选稿、局部补录音频及任何仓储扩展字段均不会返回。

## 异常规则

- 空作品 ID 返回 `INVALID_ARGUMENT`，不查询仓储。
- 作品没有已确认故事卡时返回 `STORY_CARD_NOT_FOUND`。
