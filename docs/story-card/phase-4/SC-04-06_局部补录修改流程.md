# SC-04-06 局部补录修改流程

**任务：** SC-04-06
**状态：** 已实现，待阶段 4 统一验收
**范围：** 将局部补录送入故事处理并在再次确认后更新最终文字；始终保留正式完整原始音频，不实现 UI 或完整重录。

## 流程规则

1. 局部补录只适用于已有正式故事卡的当前已完成作品；无卡返回 `STORY_CARD_NOT_FOUND`，作品或类型不一致返回 `INVALID_ARGUMENT`。
2. 合法 `partial_supplement` 通过阶段 3 故事处理服务生成临时候选稿，处理阶段不创建或覆盖正式卡片。
3. 候选稿经编辑并再次确认后，更新当前作品图片、最终标题、最终故事和确认日期。
4. 确认时从已有正式卡片复制 `originalAudioRef`；局部补录音频不会被提升、保存到正式卡片或替换完整原始音频。
