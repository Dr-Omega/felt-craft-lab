# SC-04-02 正式确认命令

**任务：** SC-04-02
**状态：** 已实现，待阶段 4 统一验收
**范围：** 提供唯一的应用层正式确认命令，将已编辑的标题、故事正文、当前作品图片、完整原始录音及确认时间写入或覆盖正式作品故事卡；不实现 UI 或日期生成。

## 命令边界

- `confirmStoryCard` 是阶段 4 面向确认操作的唯一入口；调用它之前不会创建或覆盖正式故事卡。
- 命令使用 `StoryCardEditPayload` 中的 `workId`、标题和故事正文，并由调用方提供当前作品上下文、完整录音与确认时间。
- 命令复用阶段 2 的受保护完整录音提升逻辑：仅完整首录或完整重录可成为正式原始音频；录音与编辑载荷的作品不一致时不写入卡片，也不提升录音。
- 若该作品已有正式卡片，命令覆盖原卡；不存在时创建原卡，保持“一件作品一张正式故事卡”。
- `SC-04-03` 已补充最终字段校验：作品上下文与编辑载荷必须指向同一作品，标题和故事正文不得为空，`confirmedAt` 必须是有效的 UTC ISO 8601 毫秒时间戳；写入时图片始终取当前作品上下文中的 `artworkImageRef`。
