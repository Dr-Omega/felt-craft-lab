# SC-04-05 完整重录流程

**任务：** SC-04-05
**状态：** 已实现，待阶段 4 统一验收
**范围：** 将已有正式故事卡的完整重录输入重新送入故事处理服务并返回候选稿；不创建 UI、不直接写入正式卡片、不实现局部补录。

## 流程规则

1. 仅已有正式故事卡的作品可开始完整重录；不存在正式卡片时返回 `STORY_CARD_NOT_FOUND`。
2. 输入必须是当前已完成作品的 `full_rerecording`；首录、局部补录或作品不一致均返回 `INVALID_ARGUMENT`。
3. 合法的完整重录会调用既有阶段 3 故事处理服务，返回临时 `StoryCardDraft`，包括可编辑候选稿、内容不足或失败结果。
4. 此步骤不调用仓储的 `create` 或 `replace`，因此旧的正式故事、正式图片和原始音频均保持不变。
5. 只有孩子／家长编辑候选稿后再次调用 `confirmStoryCard`，新完整录音才会替换旧 `originalAudioRef`，并覆盖最终标题、故事和确认日期。
