# SC-03-03 输入转写整理服务编排

**任务：** SC-03-03  
**状态：** 已实现，待阶段 3 统一验收  
**范围：** 将阶段 0／2 输入与 SC-03-01、SC-03-02 适配器串联为候选稿；不保存、确认或展示候选稿。

## 编排规则

```text
完整录音／完整重录／局部补录
  → 语音识别
  → 故事整理
  → StoryCardDraft

手动文字补充
  → 故事整理
  → StoryCardDraft
```

- 所有输入必须与当前已完成作品上下文的 `workId` 一致。
- 语音识别失败时，直接转换为 `failed` 候选稿，不调用故事整理。
- 识别结果的 `workId` 与当前作品不一致时返回 `INVALID_ARGUMENT`。
- 服务只返回临时 `StoryCardDraft`，不会持久化第一轮转写、候选稿或正式故事卡。
