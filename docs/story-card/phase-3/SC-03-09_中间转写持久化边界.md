# SC-03-09 中间转写持久化边界

**任务：** SC-03-09  
**状态：** 已实现，待阶段 3 统一验收  
**范围：** 保证第一轮转写不能进入或读出自正式故事卡持久化模型；不实现候选稿保存、录音保存或个人空间功能。

## 数据边界

- 正式 `StoryCard` 只写入 `workId`、`artworkImageRef`、`title`、`storyText`、`originalAudioRef`、`confirmedAt` 六个字段。
- `StoryCardStore.create` 与 `replace` 均通过字段白名单构造持久化记录，而不直接保存传入对象的所有运行时字段。
- 即使调用方对象在运行时附带 `firstTranscript`，该字段也不会写入数据库，且 `getByWorkId` 无法读出它。
- 中间转写仅供 SC-03 的识别和整理编排使用，不能替代正式故事正文。
