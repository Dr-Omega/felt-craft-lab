# SC-03-04 内容充分性判定与补充问题

**任务：** SC-03-04  
**状态：** 已实现，待阶段 3 统一验收  
**范围：** 在故事整理前判定内容是否不足，并生成引导问题；不润色文本、不新增情节、不保存候选稿或正式故事卡。

## MVP 判定规则

- 去除空白与常见中英文标点后，少于 **12 个有效字符** 的文本判为内容不足。
- 本阶段使用固定、可替换的确定性规则；阶段 5／真实服务联调时可由语义充分性判断替换，但返回结构不变。
- 内容不足时返回 `needs_more_input`，不是错误，也不会进入故事整理。

## 补充问题

固定返回 3 个儿童友好问题：

1. 小兔子在做什么呢？
2. 你最喜欢这幅画里的哪里？
3. 你想让小兔子和谁一起玩？

返回的候选稿不得包含建议标题、建议故事、错误、音频引用或中间转写。
