# SC-03-05 整理规则校验

**任务：** SC-03-05  
**状态：** 已实现，待阶段 3 统一验收  
**范围：** 校验候选整理稿的口语杂音与语言结构；不实现画面边界、儿童友好替换或真实模型整理。

## 校验规则

- 整理稿不得保留常见口语停顿词：`嗯`、`呃`、`那个`、`就是`、`um`、`uh`。
- 输入中的英文词必须在整理稿中原样保留，不得翻译或强行统一成中文；中文与英文混合结构保持不变。
- 整理稿与标题均去除首尾空白；空整理稿被拒绝。
- 固定 Mock 的中文、英文、中英混合样例承担“调语序、补连接词”的可复现输出验证；校验器不自行扩写故事。

违反规则时返回 `QA_BLOCKED`、`retryable: false` 的 `failed` 候选稿，不进入后续确认流程。
