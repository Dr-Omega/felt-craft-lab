# SC-03-08 失败与重试结果

**任务：** SC-03-08  
**状态：** 已实现，待阶段 3 统一验收  
**范围：** 统一识别与故事整理阶段的超时或服务失败结果；不实现自动重试、UI 提示或正式卡片持久化。

## 失败结果

- 语音识别返回失败时，服务保留其共享错误；识别服务意外抛出异常时，统一返回 `ASR_TIMEOUT`，`retryable: true`。
- 故事整理返回失败时，服务保留其 `failed` 候选稿；整理服务意外抛出异常时，统一返回 `QA_TIMEOUT`，`retryable: true`。
- 任一失败分支均只返回 `StoryCardDraft.status = 'failed'`，不返回可确认的标题或故事正文，也不创建正式故事卡。
- `retryable: true` 仅供调用方决定是否提供“重试”操作，不触发自动重试。
