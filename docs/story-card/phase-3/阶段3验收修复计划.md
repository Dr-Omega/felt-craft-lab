## 必须修复

### RF-01：候选标题纳入画面信息边界校验

**状态：** 已完成并通过验证  
**优先级：** P0  
**问题：** 当前画面边界规则只检查 `suggestedStoryText`，候选标题仍可能加入孩子未提及的背景、主体或贴纸名称。  
**修复目标：** 将候选标题与故事正文一并纳入具体作品素材名称校验；任一处出现未提及的元素时，返回 `QA_BLOCKED`。  
**影响范围：**

- `src/renderer/src/story-card/story-visual-boundary.service.ts`
- `tests/story-card/story-visual-boundary.service.test.ts`
- `tests/story-card/story-processing.integration.test.ts`（仅在需要补充入口回归覆盖时）
- `docs/story-card/phase-3/SC-03-06_画面信息边界校验.md`
- `docs/story-card/phase-3/阶段3验收用例与验证记录.md`

**不包含：** 不新增语义模型、不改变整理稿文本规则、不修改 UI 或持久化。  
**验收标准：** 孩子未提及“灯笼”时，标题或正文任一位置出现“灯笼”均被拒绝；孩子已提及的元素仍正常通过。  
**验证方式：** 运行画面边界、故事整理适配器、文本处理集成测试及三组 TypeScript 类型检查。

### RF-02：明确并实现“新情节”边界的可验证规则

**状态：** 已完成并通过验证  
**优先级：** P0  
**问题：** 当前规则仅能识别未提及的具体素材名称，不能可靠阻止未新增素材名、但擅自加入的故事事件。  
**修复目标：** 在确定产品可接受的“新情节”判定规则后，实现对应的确定性校验和回归测试，使其与当前 Mock 阶段的能力边界一致。  
**影响范围：**

- `src/renderer/src/story-card/story-visual-boundary.service.ts` 或新增同目录的专用规则服务
- `tests/story-card/story-visual-boundary.service.test.ts`
- `tests/story-card/story-processing.integration.test.ts`
- 阶段 0 Mock 数据（仅在新增固定样例确有必要时）
- `docs/story-card/phase-3/SC-03-06_画面信息边界校验.md`
- `docs/story-card/phase-3/阶段3验收用例与验证记录.md`

**已确认规则：** 允许去停顿词、调语序、补连接词和轻微情绪润色；不得新增“去哪里、做什么、遇见谁、发生什么”等核心事件。阶段 3 以受控核心动作和去向规则实现，不把未覆盖的开放式儿童想象直接判错。  
**不包含：** 不接入真实 AI 服务、不建设通用语义审核模型、不修改儿童友好措辞替换。  
**验收标准：** 至少有一组固定输入只表达既有事件、候选稿额外加入未表达事件的样例，并按确认后的规则被拒绝；合法的原始奇思妙想不被误拦截。  
**验证方式：** 运行画面边界与文本处理集成测试、全部阶段 3 回归测试及三组 TypeScript 类型检查。
