# SC-03-06 画面信息边界校验

**任务：** SC-03-06  
**状态：** 已实现，待阶段 3 统一验收  
**范围：** 校验候选稿中的作品上下文元素名称；不实现开放式语义推理或新增故事内容。

## 校验规则

- 候选标题或故事正文中出现背景、主体或贴纸的具体名称时，孩子原始输入中也必须出现该名称。
- 英文素材名称按大小写无关方式比对，避免 `Bunny` 与 `bunny` 被误判为不同素材。
- 例如，孩子只说“小兔子在月夜花园找朋友”，候选稿不得自行加入“灯笼亮亮的”或“灯笼和小兔子的故事”。
- 候选标题或故事正文不得加入孩子未说过的核心动作或去向；本阶段受控规则覆盖找朋友、玩、坐船、飞、跑、跳、睡觉、吃、唱歌、画画、游泳、遇见、帮助、救、变成及对应英文动作，也会比较“去／到某处”的去向。
- 允许去停顿词、调语序、补连接词和轻微情绪润色；例如，孩子说“一起玩”后，候选稿写成“开心地玩了起来”仍可通过。
- 违反规则时返回 `QA_BLOCKED`、`retryable: false` 的 `failed` 候选稿，阻止其进入确认流程。
- 固定 Mock 的候选故事作为本阶段“不得扩写情节”的可复现样例；未在受控动作／去向规则中的开放式语义判断仍留给后续真实服务质量验证。
