# SC-01-06 作品预览图同步服务

**任务目标：** 当作品产生最新预览图时，只同步对应正式故事卡的图片字段，保持故事内容与原始音频不变。

## 本任务实现

- 新增 `syncStoryCardArtworkImage(source, repository)`。
- 输入使用作品上下文中的 `workId` 与最新 `artworkImageRef`。
- 查询已有正式故事卡后，仅覆盖 `artworkImageRef` 并调用仓储替换。
- `title`、`storyText`、`originalAudioRef`、`confirmedAt` 全部保留。
- 找不到正式故事卡时返回 `STORY_CARD_NOT_FOUND`，不会执行替换。

## 非本任务范围

- 不实现作品编辑后的 UI 提示或“是否更新故事卡内容”选择。
- 不修改故事文字、标题、原始音频或确认时间。
- 不创建正式故事卡。
