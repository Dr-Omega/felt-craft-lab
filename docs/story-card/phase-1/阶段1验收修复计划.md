## 4. RF-05 修复过程与验证

**目标：** 找出测试场景数据与当前 `SceneDocument` 校验规则不一致的具体字段，并以最小改动恢复完整 Vitest 回归。

**已知证据：**

- 修复前完整 Vitest：31 个文件、239 项通过；2 个渲染测试文件、40 项失败。
- 失败均为 `SCENE_VALIDATION_FAILED`，集中在 `tests/renderer/editor-session.test.ts` 与 `tests/renderer/fabric-editor-adapter.test.ts`。
- 该问题在 Canvas 修复后才得以运行并暴露，不应回溯为 RF-02 失败。

**实际执行：**

1. 定位到 `mock://` 主体图片与渲染运行时资源策略不一致，以及快照校验漏传 `FELT_RESOURCE_REF_POLICY`。
2. 新增渲染专用夹具并补齐策略传参。
3. 两份渲染测试 76/76 通过；完整 Vitest 33 个文件、279 项通过。

**范围边界：** 不修改故事卡服务、持久化逻辑、页面 UI 或无关测试；若发现需要改变既有场景领域规则，必须先进行人工确认。
