# SC-01-04 作品上下文读取适配器

**任务目标：** 将已完成作品转换为故事卡的最小作品上下文，读取最新预览图、背景／主体／贴纸名称和主题，不暴露画布内部数据。

## 本任务实现

- `SceneDocument` 新增 `subject`：保存儿童生成主体的名称与图片引用；未生成主体时为 `null`。
- 数据库升级至版本 4：历史草稿和作品缺少 `subject` 时补为 `null`。
- 编辑器序列化会保留主体数据；本任务不实现主体生成、编辑器渲染或 UI。
- `adaptStoryCardWorkContext` 将 `ProjectRecord` 和对应素材快照转换为 `StoryCardWorkContext`：
  - 使用 `projectId` 作为 `workId`，使用 `previewUrl` 作为当前完整预览图；
  - 背景、贴纸使用素材中文名与主题展示名；
  - 主体使用儿童定义的名称，不附加主题；
  - 不返回素材 ID、主体图片引用、坐标、缩放、旋转或图层顺序；
  - 未完成／缺少主体返回 `WORK_NOT_COMPLETED`，缺少引用素材返回 `ASSET_NOT_FOUND`。

## 非本任务范围

- 不实现儿童图片／语音生成主体的服务、按钮或图片渲染。
- 不实现“完成作品后进入故事卡”入口（SC-01-05）。
- 不创建或更新正式故事卡。
