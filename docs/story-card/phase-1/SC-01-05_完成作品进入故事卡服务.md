# SC-01-05 完成作品进入故事卡服务

**任务目标：** 提供“完成作品后进入故事卡”的后端服务入口，对完成作品返回可开始故事卡的初始上下文。

## 本任务实现

- 新增 `enterStoryCardAfterWorkCompleted(workId, dependencies)`。
- 服务按以下顺序编排：
  1. 通过 `requireCompletedWork` 查询并校验作品；
  2. 通过 `adaptStoryCardWorkContext` 转换为故事卡最小上下文；
  3. 返回上下文给后续故事卡界面／录音流程。
- 不存在作品返回 `WORK_NOT_FOUND`；草稿作品返回 `WORK_NOT_COMPLETED`。

## 非本任务范围

- 不修改编辑器“完成作品”按钮，不进行页面跳转。
- 不创建正式故事卡，不开始录音或文本处理。
- 不实现前端测试页面；该内容属于阶段 5。
