# SC-01-03 已完成作品校验

**任务目标：** 仅允许已完成作品进入故事卡后续流程，并为“不存在”与“未完成”返回统一领域错误。

## 本任务实现

- 在 `ProjectRecord` 增加 `completionStatus: 'draft' | 'completed'`。
- 编辑器现有“完成作品”保存流程写入 `completed`。
- 本地数据库升级至版本 3：旧作品如缺少完成状态，补为 `draft`，不会被默认放行。
- 新增 `requireCompletedWork(workId, reader)`：
  - 不存在或空 `workId`：返回 `WORK_NOT_FOUND`；
  - `completionStatus` 非 `completed`：返回 `WORK_NOT_COMPLETED`；
  - 已完成：返回作品记录，供 SC-01-05 接入“完成作品后进入故事卡”流程。

## 非本任务范围

- 不跳转故事卡页面、不创建故事卡。
- 不读取背景、主体、贴纸等作品上下文（SC-01-04）。
- 不同步故事卡预览图（SC-01-06）。

## 验证方法

执行：

```powershell
pnpm exec vitest run tests/story-card/completed-work.service.test.ts tests/shared/contracts.test.ts tests/persistence/workflows.test.ts
```

预期：三类作品校验均通过；作品持久化工作流仍会生成 `completionStatus: 'completed'`；共享契约拒绝缺少或无效完成状态的作品记录。

**执行结果：** 通过。2026-09-21 执行定向测试，3 个测试文件共 34 项通过；覆盖不存在、未完成、已完成和旧数据迁移四种情况。
