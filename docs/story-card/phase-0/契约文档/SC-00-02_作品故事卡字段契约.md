# 作品故事卡字段契约

**任务：** SC-00-02  
**状态：** 已定义，待后续实现与人工确认  
**范围：** 仅定义正式故事卡的最小持久化字段；不定义候选稿、接口、录音会话或个人空间数据。

---

## 1. 契约目标

正式故事卡以 `workId` 为唯一关联键。一件作品最多对应一张正式故事卡；再次确认时覆盖该 `workId` 对应的原卡。

正式故事卡只保存已确认、可供后续个人空间和正式 UI 读取的内容。第一轮语音转写、候选稿与局部补录音均不得写入本契约。

## 2. 最小字段

```ts
interface StoryCard {
  /** 已完成作品的唯一标识，同时作为一作品一卡的关联键。 */
  workId: string

  /** 当前完整作品预览图的应用内资源引用，画面比例为 902:516。 */
  artworkImageRef: string

  /** 由系统建议、并经孩子或家长确认后保存的作品名称。 */
  title: string

  /** 经确认保存的最终故事文本。 */
  storyText: string

  /** 首次确认或完整重录后再次确认时保存的完整原始录音引用。 */
  originalAudioRef: string

  /** 用户点击“确认这就是我的故事”时的 UTC ISO 8601 时间。 */
  confirmedAt: string
}
```

## 3. 字段规则

| 字段 | 必填 | 规则 |
| --- | --- | --- |
| `workId` | 是 | 必须指向一件已完成作品；同一 `workId` 只允许一张正式故事卡。 |
| `artworkImageRef` | 是 | 必须指向当前完整作品预览图；作品画面修改后自动同步更新。 |
| `title` | 是 | 非空；系统可建议名称，但保存值必须来自确认页最终内容。 |
| `storyText` | 是 | 非空；仅保存最终确认的整理稿，保留孩子原有中文、英文或中英混合语言结构。 |
| `originalAudioRef` | 是 | 必须是完整原始录音的应用内资源引用；首次创建必须先具备该录音，手动文字仅能补充其对应故事；局部补录不得替换它。 |
| `confirmedAt` | 是 | UTC ISO 8601 格式；记录最近一次正式确认时间。 |

## 4. 明确禁止写入的字段

下列内容属于中间处理数据或后续模块数据，不得写入 `StoryCard`：

- 第一轮语音识别转写文本；
- 故事整理候选稿或候选标题；
- 局部补录音频及其转写；
- 录音会话状态、录制时长、播放进度；
- 主题学习进度、素材解锁状态、画布内部数据；
- 个人空间位置、分享社区发布状态、权限或审核信息；
- 临时 `blob:` URL、操作系统绝对路径、API 密钥或服务商原始响应。

## 5. 覆盖语义

1. 首次点击“确认这就是我的故事”时，按本契约创建正式故事卡。
2. 同一作品再次确认时，覆盖同一 `workId` 的正式故事卡。
3. 作品图片变化时，仅更新 `artworkImageRef`；故事文本与原始音频保持不变，直到用户主动选择更新故事内容并再次确认。
4. 完整重录并再次确认时，可更新 `originalAudioRef`、`title`、`storyText` 和 `confirmedAt`。
5. 局部补录并再次确认时，可更新 `title`、`storyText` 和 `confirmedAt`；不得更新 `originalAudioRef`。
