# 作品故事卡统一错误契约

**任务：** SC-00-06  
**状态：** 已定义，待后续实现与人工确认  
**范围：** 仅定义故事卡领域错误码、错误结构和重试语义；不实现服务调用、重试机制或界面提示。

---

## 1. 契约目标

故事卡的输入校验、作品读取、语音识别、故事整理和正式卡片读取必须返回同一种安全错误结构。调用方只能依据稳定错误码、用户可读提示和 `retryable` 决定下一步，不能依赖服务商原始错误信息。

“内容不足”不属于错误：当系统成功判断孩子提供的内容不足以整理为完整故事时，必须返回 `StoryCardDraft.status = 'needs_more_input'` 和 2–3 个补充问题，而不是返回 `StoryCardError`。

## 2. 最小字段

```ts
type StoryCardErrorCode =
  | 'EMPTY_INPUT'
  | 'AUDIO_TOO_LONG'
  | 'ASR_TIMEOUT'
  | 'ASR_EMPTY_TRANSCRIPT'
  | 'QA_TIMEOUT'
  | 'WORK_NOT_FOUND'
  | 'WORK_NOT_COMPLETED'
  | 'STORY_CARD_NOT_FOUND'

interface StoryCardError {
  code: StoryCardErrorCode
  message: string
  retryable: boolean
}
```

## 3. 错误码与重试规则

| 错误码 | 触发条件 | 默认 `retryable` | 调用方建议动作 |
| --- | --- | --- | --- |
| `EMPTY_INPUT` | 手动文本为空，或未提交任何有效输入。 | `false` | 提示孩子录音、补充文字或重新提交。 |
| `AUDIO_TOO_LONG` | 完整录音或局部补录超过 300000 ms。 | `false` | 提示缩短或重新录制。 |
| `ASR_TIMEOUT` | 语音识别服务超时。 | `true` | 保留当前输入，允许稍后重新提交。 |
| `ASR_EMPTY_TRANSCRIPT` | 未识别到清楚的语音内容。 | `false` | 提示重新录制或补充文字。 |
| `QA_TIMEOUT` | 故事整理服务超时。 | `true` | 保留当前输入，允许稍后重新提交。 |
| `WORK_NOT_FOUND` | `workId` 不存在。 | `false` | 返回作品列表或提示重新选择作品。 |
| `WORK_NOT_COMPLETED` | 作品尚未完成即进入故事卡流程。 | `false` | 返回作品继续完成后再进入故事卡。 |
| `STORY_CARD_NOT_FOUND` | 查询、更新或确认目标故事卡时不存在对应记录。 | `false` | 提示重新创建故事卡或刷新当前作品状态。 |

本契约不定义 `CONTENT_INSUFFICIENT` 错误码；内容不足的处理规则由候选稿契约统一定义。

## 4. 安全边界

- `message` 必须为面向用户或调用方的安全提示；
- 不得返回服务商错误码、原始响应、调试堆栈、请求体、音频内容、第一轮转写、密钥、绝对路径或签名链接；
- `retryable: true` 不代表自动重试，必须由用户或调用方显式触发下一次请求；
- 后续新增错误码必须先更新本契约及相应测试，再进入实现；不得在单一服务中私自返回未定义字符串。

## 5. 使用关系

```text
输入校验／作品读取／语音识别／故事整理／故事卡读取
→ StoryCardError
→ StoryCardDraft.failed 或调用方错误结果
```
