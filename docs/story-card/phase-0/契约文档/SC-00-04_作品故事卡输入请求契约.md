# 作品故事卡输入请求契约

**任务：** SC-00-04  
**状态：** 已定义，待后续实现与人工确认  
**范围：** 仅定义故事处理的四种输入请求；不定义录音状态、文件保存、候选稿或正式故事卡写入。

---

## 1. 契约目标

故事处理服务必须能够区分初次完整录音、手动文本、完整重录和局部补录。四种请求均关联一件已完成作品，但其对最终原始音频和故事文本的后续影响不同。

本契约只描述调用故事处理服务前的输入。是否写入候选稿、是否替换正式原始音频、是否覆盖正式故事卡，由后续处理和确认任务决定。

## 2. 最小字段

```ts
type StoryCardInputKind =
  | 'initial_full_recording'
  | 'manual_text'
  | 'full_rerecording'
  | 'partial_supplement'

interface StoryCardAudioInputRequest {
  workId: string
  kind:
    | 'initial_full_recording'
    | 'full_rerecording'
    | 'partial_supplement'
  audioRef: string
  durationMs: number
}

interface StoryCardManualTextInputRequest {
  workId: string
  kind: 'manual_text'
  text: string
  baseOriginalAudioRef: string
}

type StoryCardInputRequest =
  | StoryCardAudioInputRequest
  | StoryCardManualTextInputRequest
```

## 3. 四种请求的语义

| `kind` | 使用时机 | 输入内容 | 后续意图 |
| --- | --- | --- | --- |
| `initial_full_recording` | 首次创建故事卡时，孩子录制完整故事。 | 完整录音引用与时长。 | 经处理、编辑和确认后，可成为正式原始音频。 |
| `manual_text` | 已录制完整故事后，孩子或家长补充或修改文字。 | 非空文本与已有完整原始音频引用。 | 用于更新候选标题与故事；不得以纯文字首次创建正式故事卡。 |
| `full_rerecording` | 已有故事卡后，用户选择重新录制完整故事。 | 新完整录音引用与时长。 | 经重新处理和确认后，可替换正式原始音频。 |
| `partial_supplement` | 已有故事卡后，用户只补录修改的部分。 | 局部补录引用与时长。 | 仅辅助更新候选／正式故事文字；不得替换正式原始音频。 |

## 4. 字段校验规则

| 字段 | 规则 |
| --- | --- |
| `workId` | 必填，必须指向已完成作品。 |
| `kind` | 必填，必须是四种已定义值之一。 |
| `audioRef` | 仅音频请求必填；必须是应用管理的临时资源引用，不得为 `blob:` URL、操作系统绝对路径或远程签名链接。 |
| `durationMs` | 仅音频请求必填；必须为大于 0 的整数；不得超过 300000（5 分钟）。 |
| `text` | 仅手动文本请求必填；去除首尾空白后不得为空。 |
| `baseOriginalAudioRef` | 仅手动文本请求必填；必须指向本次完整录音或已有故事卡的完整原始音频。 |

## 5. 明确禁止的组合

- `manual_text` 不得携带新的 `audioRef` 或 `durationMs`，但必须携带已有完整录音的 `baseOriginalAudioRef`；
- 任一音频请求不得携带故事整理结果、建议标题或最终故事文本；
- `partial_supplement` 不得被标记为完整重录或直接替换正式原始音频；
- 请求中不得包含第一轮转写、服务商原始参数、API 密钥、临时文件系统路径或个人空间信息；
- 同一请求不得同时包含手动文本和新的音频上传作为双输入来源；`baseOriginalAudioRef` 仅用于关联已有完整录音，不是新的音频输入。

## 6. 与后续契约的关系

```text
StoryCardInputRequest
→ 语音识别／文本接收
→ StoryCardDraft
→ 用户编辑并确认
→ StoryCard
```

- 音频请求的录制、暂停、重录与临时文件清理由阶段 2 定义；
- 文本整理结果由候选稿契约承载；
- 正式故事卡字段与覆盖规则见《作品故事卡字段契约》；
- 本契约不直接写入正式故事卡。
