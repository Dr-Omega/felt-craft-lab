# 作品故事卡候选稿契约

**任务：** SC-00-03  
**状态：** 已定义；候选稿类型与阶段 3 的整理 Mock 已实现，正式确认仍待阶段 4。  
**范围：** 仅定义故事处理期间的候选稿状态与字段；不定义输入请求、录音会话、正式故事卡或接口路由。

---

## 1. 契约目标

候选稿是一次故事处理的临时结果，用于向测试界面或后续正式 UI 表达当前处理状态、可编辑的建议内容、内容不足引导或失败信息。

候选稿不等于正式故事卡。只有用户点击“确认这就是我的故事”后，候选标题和候选故事才可写入正式 `StoryCard`。

## 2. 最小字段

```ts
type StoryCardDraftStatus =
  | 'processing'
  | 'ready_for_review'
  | 'needs_more_input'
  | 'failed'

interface StoryCardDraft {
  /** 当前处理所属的已完成作品。 */
  workId: string

  /** 当前候选稿处理状态。 */
  status: StoryCardDraftStatus

  /** 系统生成的建议作品名称，仅在 ready_for_review 时提供。 */
  suggestedTitle?: string

  /** 系统整理后的候选故事，仅在 ready_for_review 时提供。 */
  suggestedStoryText?: string

  /** 内容不足时返回的 2–3 个补充问题，仅在 needs_more_input 时提供。 */
  followUpQuestions?: string[]

  /** 无法继续处理时返回的规范化错误，仅在 failed 时提供。 */
  error?: StoryCardError
}
```

`StoryCardError` 由《SC-00-06_统一错误契约》统一定义。

## 3. 状态规则

| 状态 | 必须提供 | 不得提供 | 含义 |
| --- | --- | --- | --- |
| `processing` | `workId`、`status` | `suggestedTitle`、`suggestedStoryText`、`followUpQuestions`、`error` | 输入已接收，正在转写或整理。 |
| `ready_for_review` | `workId`、`status`、`suggestedTitle`、`suggestedStoryText` | `followUpQuestions`、`error` | 已得到可编辑候选标题和故事，等待用户确认。 |
| `needs_more_input` | `workId`、`status`、`followUpQuestions` | `suggestedTitle`、`suggestedStoryText`、`error` | 输入不足，需引导孩子补充，不得自动生成完整故事。 |
| `failed` | `workId`、`status`、`error` | `suggestedTitle`、`suggestedStoryText`、`followUpQuestions` | 当前处理失败；由 `retryable` 标明是否可直接重试。 |

`needs_more_input` 是正常、可继续的处理结果：系统已成功判断输入不足，并等待孩子补充内容。它不得携带 `StoryCardError`，也不得被记录为服务失败。

## 4. 字段规则

| 字段 | 规则 |
| --- | --- |
| `workId` | 必须指向已完成作品；不存在或未完成时返回 `failed`。 |
| `suggestedTitle` | 非空建议标题；最终保存前可由孩子或家长修改。 |
| `suggestedStoryText` | 仅包含整理后的候选故事；保持孩子原语言结构，不得扩写未明确表达的内容。 |
| `followUpQuestions` | 数量必须为 2 或 3；使用儿童可理解的简短问题。 |
| `error.code` | 用于程序判断；不得透出服务商内部错误码或原始响应。 |
| `error.message` | 面向调用方的安全提示；不得含密钥、绝对路径或原始请求内容。 |
| `error.retryable` | `true` 表示可在修正输入或服务恢复后重试；不代表自动无限重试。 |

## 5. 数据边界

候选稿不得包含或向调用方返回：

- 第一轮语音转写原文；
- 完整原始音频或局部补录音的资源引用；
- 录音会话状态、播放进度或临时文件路径；
- 画布内部数据、素材解锁状态或个人空间数据；
- API 密钥、服务商原始响应、调试堆栈或操作系统绝对路径。

候选稿可以在用户编辑、重新处理或退出流程后被丢弃；其生命周期和清理方式由后续输入资产管理任务定义。
