# 作品故事卡作品上下文契约

**任务：** SC-00-05  
**状态：** 已定义，待后续实现与人工确认  
**范围：** 仅定义故事卡读取已完成作品所需的最小上下文；不定义画布内部数据、素材解锁、作品完成事件或故事处理逻辑。

---

## 1. 契约目标

故事卡服务只需读取完成作品的唯一标识、最新完整预览图，以及背景、主体、贴纸的显示名称与主题信息。该上下文用于：

1. 将故事卡关联到正确的已完成作品；
2. 在作品修改后同步故事卡图片；
3. 供故事整理服务核对孩子已明确提及的画面内容。

作品上下文不是画布持久化模型的副本。故事卡不得依赖对象坐标、缩放、旋转、图层顺序或素材解锁状态。

## 2. 最小字段

```ts
interface StoryCardWorkElement {
  /** 面向儿童和故事整理服务的显示名称。 */
  name: string

  /** 元素所属主题；无主题归属的儿童主体可为空。 */
  themeName?: string
}

interface StoryCardWorkContext {
  /** 已完成作品的唯一标识。 */
  workId: string

  /** 此上下文仅接受已完成作品。 */
  completionStatus: 'completed'

  /** 当前完整作品预览图的应用内资源引用，比例为 902:516。 */
  artworkImageRef: string

  /** 作品背景；无背景创作时为 null。 */
  background: StoryCardWorkElement | null

  /** 作品的主体图案。 */
  subject: StoryCardWorkElement

  /** 作品中使用的装饰贴纸，可为空数组。 */
  stickers: StoryCardWorkElement[]
}
```

## 3. 字段规则

| 字段 | 规则 |
| --- | --- |
| `workId` | 必填，必须是作品系统中的稳定唯一标识。 |
| `completionStatus` | 固定为 `completed`；非完成作品不得返回本契约。 |
| `artworkImageRef` | 必填，必须指向当前完整作品预览图；不得为 `blob:` URL、绝对路径或带签名的远程链接。 |
| `background` | 可为 `null`，对应无背景创作；非空时必须提供名称。 |
| `subject` | 必填，必须提供名称；若主体没有主题归属，可省略 `themeName`。 |
| `stickers` | 必填数组；每个贴纸必须提供名称；允许跨主题组合。 |
| `themeName` | 主题素材应提供主题名称；儿童自创主体无主题归属时可省略。 |

## 4. 使用边界

- 故事整理服务只能将本上下文用于核对孩子已经说出的画面信息；
- 孩子未明确提及的背景、主体或贴纸不得被服务主动点名；
- 服务可使用“画面里的这些小伙伴”等笼统衔接，但不得依据上下文新增人物、物品、动作或情节；
- `artworkImageRef` 变化时，由后续作品更新流程同步正式故事卡的图片；
- 本契约不包含或暴露素材 ID、画布坐标、资源路径、解锁状态、个人空间数据、分享数据、第一轮转写或原始音频。

## 5. 示例

```ts
const context: StoryCardWorkContext = {
  workId: 'work-001',
  completionStatus: 'completed',
  artworkImageRef: 'felt-resource://preview/work-001.png',
  background: { name: '月夜花园', themeName: '中秋' },
  subject: { name: '我的小兔子' },
  stickers: [
    { name: '灯笼', themeName: '中秋' },
    { name: '蝴蝶结', themeName: '装饰' }
  ]
}
```
