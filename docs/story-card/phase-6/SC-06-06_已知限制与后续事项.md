# SC-06-06 已知限制与后续事项

**任务状态：** 已完成并通过人工审阅  
**范围：** 说明当前故事卡模块的交付边界与后续工作归属；不改变现有功能、服务配置或产品范围。

## 当前可交付能力

- 已完成作品可进入故事卡流程；完整录音、文字补充、内容不足引导、候选编辑、明确确认、详情读取和作品更新决策均已有领域实现与验证。
- 正式故事卡只保留作品关联、当前作品图、标题、最终正文、完整原始音频和确认时间。
- 固定 Mock 可用于功能回归；真实服务可在本机网关和密钥均可用时，显式处理完整录音及文字补充。
- 阶段 5 页面是功能测试入口，不是正式 UI。

## 已知限制

| 分类 | 当前限制 | 对用户的影响 | 后续归属 |
| --- | --- | --- | --- |
| 方言与识别质量 | 当前仅对普通话、英文和中英混合的既有样例／服务路径进行验证；没有方言识别质量承诺。 | 方言、儿童发音不清或强噪声环境可能得到空转写、错误转写或需重试的结果。 | 语音服务评测与模型策略阶段。 |
| 真实 AI 服务 | 真实转写和整理依赖本机网关、网络、服务商配置及密钥；测试页只在用户显式点击时调用。 | 服务不可用时不能生成候选稿，但不会生成正式故事卡；用户应看到可重试提示。 | 服务运维、监控、超时策略与降级方案阶段。 |
| 故事整理质量 | 整理会受模型输出影响；现有规则限制画面越界和不适宜措辞，但不提供故事质量评分或人工审核。 | 个别候选稿仍可能需要儿童／家长编辑后确认。 | 提示词评测、人工审核与质量监控阶段。 |
| 正式 UI | 当前只有用于验收的测试页面，没有儿童化视觉、动效、响应式方案、可访问性完整设计或正式信息架构落地。 | 不能把当前测试页当作正式用户界面发布。 | 产品设计与正式前端开发阶段。 |
| 个人空间 | 已提供字段与接入说明，但未实现个人空间列表、详情页、缓存、空状态视觉或入口串联。 | 已确认故事卡不会在当前模块中自动出现在个人空间页面。 | 个人空间团队。 |
| 社区分享与权限 | 未实现分享页面、可见范围、家长授权、内容审核、举报、删除、导出或打印。 | 当前故事卡仅限应用内既有读取能力，不能作为公开社区内容。 | 社区、隐私与合规团队。 |
| 更新流程测试入口 | 测试页提供更新候选稿的再次确认入口；完整重录必须使用新的临时完整录音，局部补录保留原完整音频。 | 该入口仅供验收，不代表正式 UI。 | 正式 UI 接入时复用相同确认语义并设计正式交互。 |

## 后续优先级建议

1. **发布前必须完成：** 正式 UI、真实服务可用性监控／错误反馈、儿童与家长的人工回归、方言和噪声样本评测。
2. **个人空间上线前必须完成：** 接入正式故事卡读取、空状态、图片与原始音频播放器、覆盖后刷新策略。
3. **分享上线前必须完成：** 家长授权、可见范围、内容审核、举报／删除流程与隐私评估。
4. **体验优化：** 丰富内容不足的补充引导、优化候选故事编辑体验、补足更新候选稿再次确认的正式 UI。

## 不应通过后续事项改变的规则

- 不保存或展示第一轮原始转写、候选稿、临时音频或局部补录音。
- 一件作品仍只对应一张正式故事卡；重新确认覆盖原卡。
- 局部补录不替换完整原始音频；只有完整重录再次确认才可替换。
- AI 不得主动补写儿童未说出的画面元素、人物、动作或情节。

## 审阅检查

- 限制是否覆盖方言、真实服务质量、正式 UI、个人空间和社区分享。
- 后续事项是否明确归属，且没有把未实现能力描述为已交付。
- 不可变数据与安全规则是否仍与正式故事卡契约一致。
