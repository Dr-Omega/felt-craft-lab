# SC-06-05 正式 UI 接入说明

**任务状态：** 已完成并通过人工审阅  
**接入对象：** 后续正式故事卡页面与交互实现。  
**范围：** 约定页面状态、可用操作、不可变规则和本阶段非目标；不复用阶段 5 测试页的视觉或布局。

## 页面状态与允许操作

| 页面状态 | 应展示的信息 | 允许操作 | 不允许操作 |
| --- | --- | --- | --- |
| 完成作品后的引导页 | 当前作品预览和儿童友好引导语 | 开始讲故事、返回作品 | 对未完成作品开始故事卡流程 |
| 完整录音页 | 作品预览、录音状态和累计时长 | 开始、暂停、继续、结束、重录 | 超过 5 分钟继续录音；以纯文字首次创建故事卡 |
| 录音结束后的补充页 | 已完成录音状态、文字补充入口 | 填写／修改补充文字、提交处理、重录 | 将补充文字作为正式原始音频 |
| 处理中 | 明确的处理中状态 | 等待、取消或返回输入（具体交互由 UI 设计定义） | 将处理中或失败结果保存为正式卡 |
| 内容不足页 | 2–3 个儿童易懂的补充问题 | 继续录音、文字补充、重录 | 自行补写完整故事；把 `needs_more_input` 当作错误 |
| 候选编辑页 | 候选标题、候选正文、当前完整录音播放器 | 编辑标题和正文、返回修改输入、确认 | 在确认前展示为正式卡；展示第一轮转写 |
| 正式详情页 | 作品图、标题、确认日期、最终正文、完整原始音频 | 播放／暂停、拖动进度、发起作品内容更新选择 | 编辑或替换未进入确认流程的正式字段 |
| 作品更新选择 | 已同步的作品图片、三种内容更新选择 | 保持故事、完整重录、局部补录 | 因局部补录替换完整原始音频 |

## 状态迁移

```text
完成作品
  → 引导页
  → 完整录音／文字补充
  → 处理中
  ├─ 内容不足 → 补充输入 → 处理中
  └─ 候选编辑 → 明确确认 → 正式详情

作品图片更新
  → 正式详情图片同步
  → 保持故事／完整重录／局部补录
```

失败或超时应保留在当前输入上下文中，展示可理解的错误和重试入口；不得生成候选以外的正式卡片。

## 不可变业务规则

1. 只有已完成作品可进入流程，且首次确认必须关联一段完整录音。
2. 录音上限为 5 分钟；暂停、继续和重录不得绕过该上限。
3. 文字补充只能关联已有完整录音，不能独立创建正式故事卡。
4. 候选标题和正文可以编辑，但只有“确认”命令可创建或覆盖正式故事卡。
5. 每个 `workId` 只保留一张正式卡；再次确认覆盖原卡。
6. 正式详情只展示作品图、标题、确认日期、最终正文和完整原始音频；不展示第一轮转写、候选稿、补录片段或服务原始响应。
7. 作品图片变化时自动同步图片；保持故事不改文字或音频，局部补录不替换原始音频，完整重录再次确认后才替换原始音频。
8. 整理结果必须保留儿童原语言结构、不得新增未提及的素材或情节，并将不适宜措辞改为儿童友好表达。

## 接入边界

- 正式 UI 从领域服务和 `getStoryCardDetail` 读取数据，不直接访问临时录音文件、数据库记录或 AI 网关响应。
- 页面可自行设计儿童化视觉、动效和响应式布局，但不得改变上述状态、字段和确认语义。
- 资源只使用 `artworkImageRef` 与 `originalAudioRef`；音频播放器不得播放局部补录或临时录音。
- 确认前的候选数据只能保存在页面状态或受控临时状态中，不能作为个人空间展示内容。

## 本阶段不做事项

- 不实现正式视觉稿、儿童化插画、动效、响应式细节或设计系统；
- 不实现个人空间、社区分享、权限、审核、导出、PDF 或打印；
- 不提供故事卡版本历史、多卡对比或原始转写查看；
- 不承诺方言识别质量，也不将模型参数、密钥或服务诊断暴露给 UI。
