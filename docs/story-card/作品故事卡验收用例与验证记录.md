# 作品故事卡验收用例与验证记录

**依据：**《作品故事卡 PRD》V1.0  
**用途：** 将 AC-01 至 AC-15 转为可执行验收场景，并持续记录每个开发任务的验证方式与结果。  
**当前状态：** 阶段 0 契约与 Mock 已完成，并通过重新验收；功能验证待后续实现。

---

## 1. 执行约定

- 每项验收用例在对应功能实现后执行；未实现前不得标记为“通过”。
- 自动化测试记录测试文件、命令和结果；人工测试记录操作步骤和结果。
- 任何失败必须记录实际结果、关联任务和后续处理，不以“预期通过”替代证据。
- 正式 UI 视觉效果不属于本阶段验收范围；测试界面仅用于验证功能路径。
