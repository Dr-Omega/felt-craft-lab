# 类别1｜植物（plants）

**所属单元：** 第四章 · 动植物主题  
**themeId：** `plants`

**说明：** 介绍=简介+相关诗句（用户原文）。

## 背景介绍

```text
古代诗人常常借助花草树木寄托志向与情感，不同的植物被赋予特定的象征意义。学习植物意象，能够帮助我们理解诗歌主旨，体会诗人蕴藏在景物之中的思想情感。
```

## 贴纸介绍

- **荷花**：荷花象征洁身自好、品性高雅，不与世俗同流合污；荷花也可用来描绘江南水乡清丽风光。相关诗句：小荷才露尖尖角，早有蜻蜓立上头。（杨万里《小池》）
- **菊花**：菊花凌霜开放，菊花象征淡泊隐逸、清高不屈，拥有坚守本心的君子品格。相关诗句：待到秋来九月八，我花开后百花杀。（黄巢《不第后赋菊》）
- **桂花**：桂花香气清幽，桂花常营造清幽静谧、空灵皎洁的月夜意境，暗含恬静悠远之感。相关诗句：人闲桂花落，夜静春山空。（王维《鸟鸣涧》）
- **梧桐**：梧桐常与秋雨搭配出现，梧桐象征孤寂忧愁，用来寄托悲伤、绵长的思念之情。相关诗句：无言独上西楼，月如钩。寂寞梧桐深院锁清秋。（李煜《相见欢》）
- **松树**：松树寒冬常青，松树象征坚韧顽强、忠贞不屈、高洁自持的品格。相关诗句：大雪压青松，青松挺且直。（陈毅《青松》）
- **竹子**：竹子挺拔中空，竹子象征谦逊正直、清雅有节、不慕荣华的志向。相关诗句：千磨万击还坚劲，任尔东西南北风。（郑燮《竹石》）
- **梅花**：梅花寒冬傲雪绽放，梅花象征不畏艰难、坚贞高洁、不屈不挠的精神。相关诗句：墙角数枝梅，凌寒独自开。（王安石《梅花》）
